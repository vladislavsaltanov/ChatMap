# ChatMap — Project Context

## О проекте
ChatMap — локальное одностраничное веб-приложение, превращающее официальный JSON-экспорт Telegram-чата в интерактивную карту совместной встречаемости слов.
- Узлы: слова (размер узла пропорционален частоте встречаемости).
- Рёбра: совместная встречаемость слов в рамках сообщений/серий/ответов (толщина ребра пропорциональна совместному весу).
- Цвета узлов: преобладающий автор слова (стартовые цвета с золотым сечением шага hue $137.5^\circ \cdot i$).
- Строго локальная работа: ни одного сетевого запроса с данными чата.

## Архитектура
1. **Web Worker (`src/core/worker.ts`):**
   - Парсинг JSON-экспорта (`parse.ts`) с поддержкой официального Telegram Desktop (одиночные чаты и полный экспорт `chats.list`), AyuGram, автоматической очисткой UTF-8 BOM, поддержкой ISO-дат и unixtime, сохранением реальных имён участников.
   - Токенизация и классификация (`tokenize.ts`), фильтры стоп-слов, мата и смеха (`filters.ts`).
   - Канонизация стеммером (`canon.ts`) и интернирование идентификаторов (`intern.ts`).
   - Подсчёт частот и связей (`tally.ts`): объединение серий сообщений (до 120 с, кап 30 токенов), учёт реплаев, оптимизированные SMI-ключи рёбер.
   - Умные склейки опечаток (`smart-merge.ts`): триграммное сходство Жаккара $\ge 0.5$ для слов длины $\ge 6$.
   - Выборка подграфа (`select.ts`): режимы «вместе», «только автор», «пересечения» (для 2 участников), отсечка по top-N и минимальному весу.
   - Построение графа и укладка (`geometry.ts`, `graph.ts`, `worker.ts`): частотно-зависимое масштабирование узлов (`nodeFitSize`) — крупные ячейки с полным текстом для частых ключевых слов и мелкие аккуратные точки (4–9px) для редких слов; фильтрация скелета связей (backbone filter: до 4 сильнейших связей на узел + магистрали $w \ge 4$), исключающая паутину спагетти; динамическая градация веса и цвета рёбер (`edgeWidth`, `edgeColor`) от приглушенных полупрозрачных фоновых связей (`rgba(36, 44, 68, 0.20)`) до светящихся сине-белых магистралей (`#b4cdfff2`); весо-чувствительная физика ForceAtlas2 (`edgeWeightInfluence: 1.4`, `scalingRatio: 2800`, `gravity: 0.0004`), стягивающая часто используемые вместе слова (включая реплаи) близко друг к другу, при этом относя редкие пары далеко на периферию; завершающий итеративный релаксационный проход устранения коллизий (`resolveCollisions`), гарантирующий свободный зазор $\ge 12$px между всеми узлами; кеширование позиций (`prevXY`) при фильтрации.

2. **Main Thread & UI (`src/ui/`):**
   - `landing.ts`: Drag & Drop зона, выбор файла, предупреждение при размере $>200$ МБ, поддержка dev-режима `?fixture=1`.
   - `progress.ts`: индикация этапов обработки с визуальным прогресс-баром и описанием стадий (чтение файла, токенизация, укладка).
   - `mapview.ts`: рендеринг через Sigma.js v4 WebGL в метрическом пространстве графа (`itemSizesReference: 'positions'`, `zoomToSizeRatioFunction: (ratio) => ratio`), синхронное масштабирование шрифта под узлы (`zoomToLabelSizeRatioFunction`), адаптивная видимость подписей (`labelVisibility: 'auto'`, `labelRenderedSizeThreshold: 13`) — подписи мелких слов скрыты в общем виде и проявляются при приближении камеры или наведении, центрирование слов внутри ячеек (`labelPosition: 'over'`), полужирный шрифт 10px, автоматическое кадрирование графа (`autoRescaleContent: 'nodes'`, `stagePadding: 50`), стабильная подсветка без эффекта поворота, белые ореолы подсветки активных узлов (3px) и светящиеся рёбра эго-сети, экспорт PNG $2560 \times 1440$ (`@sigma/export-image`).
   - `controls.ts`: боковой drawer с переключением режимов, фильтрами, слайдерами (top-N, мин. вес), кастомными словами, тумблером умных склеек и палитрой авторов.
   - `nodepanel.ts`: правая панель деталей узла при pin (частота, топ-3 соседа с переходом, список словоформ, переопределение лейбла с сохранением в `localStorage`).

3. **Стили (`src/styles/`):**
   - `@layer tokens, base, map`.
   - Тёмная тема (`--paper: oklch(0.16 0.01 85)`), без градиентов и маркетингового шума.
   - Соблюдение стандартов доступности (touch-таргеты $\ge 40$px, `font-variant-numeric: tabular-nums`, контрастный `:focus-visible`).

## Статус реализации
Все 13 задач спецификации и плана (`docs/superpowers/plans/2026-10-31-chatmap.md`) полностью завершены:
- Task 1: Скелет проекта, токены, экраны.
- Task 2: Парсер Telegram JSON.
- Task 3: Токенизатор и канонизатор.
- Task 4: Фильтры (стоп-слова, мат, смех).
- Task 5: Tally (подсчёт частот и пар в окнах/сериях/реплаях).
- Task 6: Select (режимы отображения и веса).
- Task 7: Smart-merge (триграммные склейки).
- Task 8: Воркер, Graphology, ForceAtlas2 layout с кешем позиций.
- Task 9: Поток загрузки и связывание UI с воркером.
- Task 10: Рендеринг карты Sigma v4, hover, pin, зум.
- Task 11: Панель управления (controls drawer) с debounce.
- Task 12: Панель узла (nodepanel) с формами и оверрайдом лейблов.
- Task 13: Экспорт в PNG $2560 \times 1440$ и полировка доступности.

## Команды
- `npm.cmd run dev` — запуск локального dev-сервера Vite.
- `npm.cmd run test` — запуск юнит-тестов Vitest (`tests/`).
- `npm.cmd run typecheck` — проверка типов TypeScript (`tsc --noEmit`).
- `npm.cmd run build` — сборка проекта для продакшена (`dist/`).

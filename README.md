# ChatMap

Одна страница, которая превращает официальный JSON-экспорт Telegram-чата в карту слов.

## Как это работает

1. Скачай экспорт чата: Telegram Desktop → Настройки → Экспорт → «Машиночитаемый экспорт (JSON)». Подходит и AyuGram.
2. Открой страницу ChatMap, перетащи `result.json` в окно.
3. Смотри карту: узлы — слова, размер узла = частота; рёбра — совместные встречи слов, чем ярче ребро, тем чаще; цвета — голоса участников.

## Что можно делать

- Режимы: **вместе**, **только один участник**, **пересечения** (для личного чата).
- Фильтры пересобирают карту на лету: мат, смех, ссылки-код, числа.
- Наведи курсор — подсвечивается окружение слова; клик закрепляет и открывает панель со всеми формами слова.
- Сохранение картинки PNG 2560×1440.

## Приватность

Работа строго локальная: файл чата загружается в браузер и никуда не отправляется. После первой загрузки страница работает офлайн.

## Технологии

TypeScript, sigma.js, graphology, Vite. Только фронтенд, статик-хостинг.

# Импорт, режимы и фильтры

## Загрузка файла

Экран landing принимает `result.json` перетаскиванием или выбором файла.
Инструкция на экране: Telegram Desktop → экспорт истории чата →
машиночитаемый JSON без медиа.

Лимиты на входе:

- больше 200 МБ — предупреждение о долгой обработке;
- больше 500 МБ — жёсткий предел лендинга.

`main.ts` читает файл через `FileReader` как текст и шлёт воркеру
сообщение `{ type: 'open', json }`. Не-JSON завершается диалогом ошибки
и возвратом на landing.

## Прогресс

Экран progress показывает полосу и стадию:
чтение файла, токенизация и фильтрация, подсчёт частот,
умные склейки, выборка, раскладка ForceAtlas2, формирование карты.
Сообщения `{ type: 'progress', done, total, stage }` идут из воркера.

После полного прогона воркер присылает `ready`:
список авторов с именами и числом слов, число сообщений.
Только затем приходит `map` с узлами, рёбрами и формами.

## Режимы голосов

- **Вместе** — общая карта всех участников.
- **Автор** — только встречи выбранного участника.
- **Пересечения** — только межрепликовые встречи;
  доступна только при числе участников ≤ 2.

Смена режима — это `select()` заново по уже посчитанному tally,
без повторного парсинга. Кэш позиций держит карту стабильной.

## Фильтры на лету

Панель управления отдаёт воркеру `{ type: 'update', cfg }`
с дебаунсом. Флаги — это show-flags: `mat`, `laugh`, `tech`,
`digits`, `stopwords`, плюс `smartMerge` и кастомные списки.
Слайдеры `topN` и `minWeight` управляют обрезкой выборки.

Пересборка идёт по кэшированному конвейеру: меняются только
затронутые стадии, карта обновляется без перезагрузки файла.

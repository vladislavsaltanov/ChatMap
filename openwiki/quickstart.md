# Быстрый старт

## 1. Выгрузи чат

Telegram Desktop → нужный чат → ⋮ → Экспорт истории чата →
формат «Машиночитаемый JSON», медиа снять.
Подойдёт и AyuGram. Получишь `result.json`.

## 2. Открой карту

Открой ChatMap (`npm run dev`) и перетащи `result.json` в окно
или выбери файл кнопкой. Дождись полосы прогресса:
токенизация, подсчёт, раскладка — затем появится карта.

## 3. Читай карту

- Узел — слово, размер = частота; ребро — совместная встреча, яркость = сила связи.
- Режимы: вместе, голос одного участника, пересечения (только для личного чата).
- Фильтры пересобирают карту на лету: мат, смех, ссылки и код, числа.
- Наведи курсор для подсветки окружения, кликни для закрепления и панели форм слова.
- Кнопка PNG сохраняет кадр 2560×1440.

Всё работает строго локально: файл читается в память вкладки,
сети нет, страница живёт офлайн. Реальный экспорт не коммить —
для тестов есть только синтетическая фикстура.

# CONVENTIONS — ChatMap

Локальный инструмент: экспорт Telegram-чата → карта слов. Один человек, offline, тёмная тема.

## § Always Green / Shift Left
Preflight зелёный до следующей задачи: `npm run typecheck && npm run test && npm run build`.
Красный гейт не игнорируется и не объясняется словом «пре-эксистинг». Лестница fix-or-log:
`quick-fix` (тривиальный дата-фикс) → `fix-bug`/`investigate-bug` (нужна TDD) → если чинить нельзя,
лог в `specs/bugs/registry.yaml` и отдельный коммит.

## § Discovered Defects
Баг, найденный по пути, чинится отдельным коммитом, не смешивается с фичей.

## § Banned dismissive phrases
| Фраза | Почему нельзя |
|---|---|
| «ошибка была до меня» | Только если доказано тестом, иначе гейт красный |
| «не относится к задаче» | Preflight общий — всё относится |
| « появилась вне моих правок» | Появилась — чиню или логирую |
| «out of scope» | ОбластиOutOfScope — в доке, не в разговоре |

## § Specs
Всё планирование живёт в `specs/`. Вердикты верификации — в `specs/verifications/`.
ADR — в `specs/adr/` (одна страница = одно решение).
Документация архитектуры и ТЗ: `HANDOFF.md` и `specs/`.

## § Тесты
- Только на чистую логику `src/core/` (vitest). UI и sigma — ручная проверка по критериям этапов.
- Тестовые кейсы берутся из §6 документации (матчеры, стеммер, tally-тройка).
- Реальный чат не коммитится; синтетическая фикстура `tests/fixtures/sample-export.json`.

## § Defensive code
| Категория | Где |
|---|---|
| Timeout / предупреждение | воркер: >200 МБ — предупреждение UI; парс с не-JSON — внятная ошибка формата |
| Graceful degradation | чужой формат файла (HTML-экспорт) → руссказ с инструкцией; N>2 участников → «пересечения» скрыта |
| Validation at boundary | всё, что приходит из файла, валидируется при parse; DOM-оверрайды localStorage чистятся молча |

## § Гит
- Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`, `test:`).
- main защищена; работа — в ветке этапа (p0, p1, ...), мерж после зелёного Preflight.

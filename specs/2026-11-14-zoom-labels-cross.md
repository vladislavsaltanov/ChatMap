# План: подписи по зуму, кегль, крестики

Дата: 2026-11-14. Запрос: «при приближении у маленьких нод надписи появлялись постепенно
(с низким порогом полной непрозрачности), а у больших так же пропадали; надписи чуть
побольше; крестики внутри нод поменьше».

## 1. Что было

- `labelAlphaFor` (`ui/mapStyles.ts`): хабы (`size >= 22`) на приближении лишь мягчели
  максимум на 30% (`1 − 0.3·hubK·zoomDepth^1.2`), никогда не исчезали. Мелкие (`< 12`)
  на приближении сразу имели альфу 1 — их держала только планка `labelMinCore`, которая
  на зуме почти не двигалась (`minCore·(0.85 + 0.15·ratio)` → всего −7.5% к ratio 0.5).
- Кегль: `LABEL_FONT_PX = 18.5`, кривая `0.62 + 0.38·t` (11.5 у пыли → 18.5 максимум).
- Крест: `somaStarRay` (`ui/neural.ts`) — полуширина рукава `smoothstep(1.10, 2.60)`,
  длина `min(coreR·0.85, 22)`, белая сердцевина `r = 3.0`.

## 2. Правка

| Что | Файл | Как |
| --- | --- | --- |
| Планка на приближении | `ui/mapStyles.ts` `labelMinCore` | при `ratio < 1`: `max(3.5, minCore·(0.45 + 0.55·smoothstep(0.35, 1.0, ratio)))` — стык с дальней веткой в 1.0 непрерывен; мелкие всплывают одна за одной, полная сила уже после ~одного тика колеса |
| Хабы на приближении | `ui/mapStyles.ts` `labelAlphaFor` | `size >= 22`: `alpha = smoothstep(0.30, 0.70, ratio)` — полное исчезновение к ratio ~0.3 вместо 30% смягчения |
| Середина без ступеньки | `ui/mapStyles.ts` `labelAlphaFor` | `12–22`: дальняя альфа × `(1 − nearK·(1 − smoothstep(0.30, 0.70, ratio)))`, `nearK = (size−12)/10` — непрерывно с обеих сторон диапазона |
| Кегль | `ui/mapStyles.ts` | `LABEL_FONT_PX = 18.5 → 20`, кривая та же (12.4 → 20); комменты про 18.5 обновить |
| Крест | `ui/neural.ts` | рукава `smoothstep(0.80, 1.90)`, длина `min(coreR·0.62, 15)`, сердцевина `r = 2.2` |

Дальнее поведение (zoom-out) не тронуто. Порог `labelIsLegible > 0.30` и гейт отрисовки
`> 0.02` не менялись: гаснущие подписи сами выпадают из резолвера коллизий.

## 3. Проверка

- `npm run typecheck` — 0 ошибок; `npm run test` — зелёный (логики `src/core/` не касались).
- `node tools/shot-shape.mjs caption …` + зонд `census`: подписи мелких появляются только
  на приближении, хабы гаснут; `labelSizeP50` подрос сообразно кеглю 20.

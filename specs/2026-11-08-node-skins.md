## 1. Принцип
Не «улучшаем ноду», а **четыре независимых языка формы**. У них общие только
геометрия квада, непрозрачная маска (рёбра не просвечивают) и цвет автора.
Ни один не использует «тёмный диск + тонкое кольцо + точка» как основу.
Переключение — униформа `u_skin`, один шейдер, без пересоздания рендерера.

| Язык | Референсы | Форма | Что кодирует частоту |
|---|---|---|---|
| **Бусина** `bead` | психосеть с пастельными бусинами, плакат LINKS | сплошной плоский диск цвета автора, волосяной ободок, блик | только размер |
| **Рамка** `frame` | технические пластины, сеть директоров, спутниковая инфографика | 4 Г-образных угловых скобы = квадратный визир + крест совмещения | размер рамки |
| **Лимб** `gauge` | светящиеся орбиты, круговые диаграммы спутников | тихая полная дорожка + яркая цветная дуга | **длина дуги** 0.9…4.6 рад |
| **Созвездие** `star` | сфера знаний, звёздное поле, dotted data-art | нет контура: орбита из светлых бусин + звезда с ореолом | **число бусин** 10…26 и радиус |

Маленькие узлы во всех языках вырождаются в точку/крест — как «пыль» в
референсах 2 и 7. Пыль не получает лимбов и орбит.

## 2. Реализация
- `src/ui/neural.ts`
  - `layer_soma` переписан: общий `SomaState`, 4 функции `skinBead / skinFrame /
    skinGauge / skinStar`, выбор по `u_skin`. Удалены апертура, внутренний лимб,
    фаска, градуировки, индексная дуга 75°, тонированная линза.
  - `NODE_SKINS`, `DEFAULT_NODE_SKIN = 'star'`, `setNodeSkin()`.
  - Униформы `somaTime` / `somaSkin` — **мутируемые объекты**: Sigma v4
    перечитывает `uniform.value` в `setUniforms()` каждый кадр. Хук
    `lifecycle.beforeRender` для этого не подходит (первая итерация не
    переключалась, пока менялась сторонняя переменная).
  - `layer_axon` не менялся: `fil += 0.16 * (1 − 0.5·s)`.
- `src/ui/controls.ts` — радиогруппа «Вид узлов» в панели параметров,
  `onNodeSkinChange`, `setNodeSkin`.
- `src/main.ts` — связь панели с шейдером, `?node=bead|frame|gauge|star`.
- Ядро, `mapStyles.ts`, `mapview.ts`, CSS, тесты — не тронуты.

## 3. Критерии приёмки
- Ни один язык не повторяет форму раунда 9/10.
- Переключение мгновенное, без ошибок GLSL и без пересчёта графа.
- На плотной карте (271 узел) читаются цвета авторов, иерархия размеров и
  новый признак (дуга / число бусин / рамка).
- Рёбра не просвечивают сквозь узел; подписи, LOD, hover/pin/фото работают.
- Preflight зелёный: typecheck, 156/156, build.
- Снимки всех четырёх языков на фикстуре и плотной карте приложены к вердикту.

## 4. Риски
| Риск | Мера |
|---|---|
| «Бусина» читается как пузырьковая диаграмма | это отдельный язык по референсам 1/4, не дефолт; дефолт — «Созвездие» |
| «Лимб» на хабах становится почти полным кольцом | sweep ограничен 4.6 рад, дорожка α 0.16, дуга яркая |
| Дробные `beadsN` дадут разрыв орбиты | `floor(... + 0.5)` |
| Переключение не подхватится рендером | мутация `uniform.value` + `scheduleRender()` |
| Слишком много опций в UI | одна радиогруппа, 4 пункта, телеграфные названия |

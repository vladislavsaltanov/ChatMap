# Эго-свечение связей: весь веер, ярусами по весу

Дата: 2026-11-11. Ветка: `main` (без worktree).

## Проблема (со слов пользователя)

До наведения видно, что у слова много связей. При наведении/выделении остаётся лишь несколько:
сейчас подсвечиваются только `topN = 8` связей (закрепление — 12), остальные тонут в общем
затемнении (`opacity × (1 − 0.93·dimAlpha)` → ~7 % яркости).

## Решение (без нового поведения в графе — только слои видимости)

Наведение/закрепление включает **весь веер связей** узла, но с ярусной яркостью по весу:

| Вес связи внутри веера | Яруc | Что рисуется |
| --- | --- | --- |
| `t < 0.35` | редкая | тускло: `opacity ≈ 0.14`, но заметно ярче затемнённого фона |
| `0.35 ≤ t < 0.65` | средняя | `opacity ≈ 0.45`, обычная толщина |
| `t ≥ 0.65` | самая частая | `opacity ≈ 0.95`, +0.5 px толщины, бегущие капли (`pulse = 1`) |

`t = (w / maxWeightOfEgo) ** 0.55` — перцептивная рампа: даже слабые связи читаются как связи,
а не как «ничего».

Узлы: **все** соседи получают новое состояние `isEgo` (без затемнения, полный размер), но
принудительные подписи и свечение остаются у `topN` сильнейших (`isActive`) — иначе на 1000 нодах
наведение заливает экран сотней подписей.

## Шаги

### Step 1 — состояние веера: `src/ui/subgraphHighlight.ts`
- `swap()` собирает ВСЕ инцидентные рёбра, считает `maxW`, ставит `setEdgeState(edge, { isActive: true, egoTier })`.
- Все соседи → `setNodeState(n, { isEgo: true })`; сильнейшие `topN` дополнительно `isActive: true`.
- Уход из веера: `isActive: false, egoTier: 0` и `isEgo: false` (никакого залипшего состояния).
- `clear()`/`reset()` сбрасывают `egoTier`/`isEgo`.
- Verify: `npm run typecheck`.

### Step 2 — ярусный стиль: `src/ui/mapStyles.ts`
- `CustomEdgeState` += `egoTier: number`; `CustomNodeState` += `isEgo: boolean`.
- Активная связь: `opacity = 0.14 + 0.82·t^1.15` смешивается с `focusAlpha` (плавный вход),
  `size = attrs.size + 0.5·t·focusAlpha`, `pulse = t ≥ 0.65 ? 1 : 0`. Без `egoTier` — прежнее поведение.
- Узлы: ветка затемнения исключает `isEgo`; новая ветка `isEgo → opacity 1, size без LOD-усадки,
  labelVisibility по обычным правилам`.
- Verify: `npm run typecheck`.

### Step 3 — вызов: `src/ui/mapview.ts`
- `focusSubgraph(key, topN)` — `topN` теперь означает только число подписанных соседей (8 на hover,
  12 на пин); комментарии соответствуют смыслу.
- Verify: `npm run typecheck`.

### Step 4 — проверка поведением: `tools/shot-shape.mjs`
- Проба `egoSweep`: навести слово-хаб, вернуть `degree`, число рёбер с `isActive`, распределение
  `opacity` по ярусам (weak/mid/strong), число `pulse = 1`, число подписанных соседей.
- Ожидание: `active === degree`, подписанных соседей = 8, ярких ≥ несколько, слабых — большинство.
- Скриншоты: обзор и сильный зум.
- Verify: `node tools/shot-shape.mjs ego 400 2000 271`.

### Step 5 — гейт
- `npm run typecheck && npx vitest run && npm run build`; отчёт в `specs/verifications/`,
  строка в `HANDOFF.md` §3.5.

## Границы

- Порог «8 подписей» не трогаем: это бюджет типографики, не связей.
- `cullTransitEdges` не меняется: рёбра веера уже в `keep`.
- Новых зависимостей нет; данные чата по-прежнему не покидают браузер.

## Риски

1. Хаб с 165 связями → 165 записей состояния на каждое наведение. Замер в Step 4 (сравнить время
   ответа на hover до/после на 1000 нодах); при просадке — понизить ярус до `O(1)`-формулы в стиле,
   а не хранить в состоянии.
2. Ярус по `w/maxW` внутри веера: у слова с одной очень сильной связью всё остальное уйдёт в
   «тускло». Приемлемо по постановке («самые частые прям со свечением»).

## Итог (выполнено)

Все шаги закрыты. Ярус считается **по рангу веса внутри веера**, а не по `w/maxWeight`:
при разбросе весов 1..500 первый вариант сваливал все 164 слабые связи в один неразличимый
ярус (замер: `weak = 0`, `mid = 150`). С рангом замер даёт `weak 45 / mid 64 / strong 56`,
`pulsing 26`, подписанных соседей 8, активных связей = степень слова (165/165).

Формулы: `tier = 1 − rank/n`, `opacity = 0.12 + 0.88·tier^1.5` (умножается на твин `focusAlpha`),
`size = base·(1 + 0.45·tier·focusAlpha)`, `pulse = 1` при `tier ≥ 0.85`.

Проверка снятия: после ухода курсора `egoNodes = 0`, `activeEdges = 0` (состояние не залипает).
Скриншоты: `tests/betterwright/shape/ego3-ego-fan-wide.png`, `ego3-ego-fan-close.png`,
`ego3-ego-cleared.png`.

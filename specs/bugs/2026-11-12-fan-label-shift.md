# 2026-11-12 — подписи соседей сдвигаются при выделении ноды

Статус: **ИСПРАВЛЕНО**.

## Симптом

Наводишь/кликаешь слово: подписи всех связанных слов прыгают вправо на несколько пикселей,
и само тело соседа меняется мгновенно — анимации нет.

## Корневая причина

Sigma ставит подпись по формуле `x + size / 2 + margin`, где `size` — квад ноды (диаметр зоны,
включая ауру). Значит любое изменение `size` на кадре ховера сдвигает текст.

В `mapStyles.ts` две ветки соседей меняют именно `size`, причём на дискретном состоянии:

```text
isEgo       size = quadOf(core)                    // без lodNodeScale
isActive    size = quadOf(core) * egoActive ? 1 : lodNodeScale(...)
base        size = quadOf(core) * lodNodeScale(...)
```

То есть при появлении фокуса квад соседа вырастает от LOD-сжатого до полного `quadOf(core)`.
Сдвиг = половина прироста: на карте 400 слов при ratio 1 `lodNodeScale` для мелкой ноды ≈ 0.59,
то есть квад 14px → 14px, а рисовалось 8.2px — текст уезжает на ~2.9px вправо за один кадр.
Никакого твина у этого перехода нет — буст включается булевым состоянием.

## Правка

Подпись не должна зависеть от того, горит ли нода. Значит соседи НЕ меняют квад вообще:
видимое тело растёт внутри того же квада через уже существующий атрибут шейдера `core`
(доля радиуса квада, `soma.c` в `layerSoma`). Это даёт «проявление» тела без сдвига типографики.

1. `src/core/geometry.ts` — `fanCoreFrac(base, lodScale, grow)`:
   `base + (min(0.96, base / lodScale) - base) · grow`. Деление на LOD-сжатие возвращает телу
   полный радиус, потолок 0.96 — предел шейдера (квад не может рисовать за своими границами).
2. `mapStyles.ts`:
   - ветки `isEgo` / `isActive` теряют `size` и получают `core: fanCore(attrs, g)`;
   - ветка `isHighlighted` возвращает `core` к базовому (фокус растёт квадом, как раньше),
     иначе она унаследовала бы фан-буст от `isEgo`.
3. Рост фана ведёт тот же твин `grow`, что и рост центра (появляется вместе с фокусом),
   уход в idle — тот же твин вниз.

## Проверка

Зонд `grow` (`tools/shot-shape.mjs`) дополнительно снимает `getNodeDisplayData` у САМОГО
тяжёлого соседа до и после наведения:

Замер на карте 400 слов / 859 связей, 274 соседа у наведённого слова:

| величина | до правки | после |
| --- | --- | --- |
| соседей со сдвигом > 0.5px | 257 из 274 | **0** |
| максимальный сдвиг подписи | 1.96px | **0 px** |
| `core` соседа (доля квада, рост) | 0 (буста не было) | **до +0.327** |
| кадры роста центра | 4 | 5 (×1.12, конец не изменился) |

То есть тело соседа проявляется изнутри квада, а подпись остаётся на месте.

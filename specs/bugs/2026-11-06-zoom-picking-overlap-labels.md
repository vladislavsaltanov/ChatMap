# 2026-11-06 — Зум, выбор ноды, перекрытия, сдвиг подписей

## Симптомы (от пользователя)
1. При отдалении камеры крупные ноды «ещё сильнее увеличиваются».
2. Ноду нельзя выделить/пиннуть, даже когда мышь «входит» в ноду.
3. Соседние ноды перекрывают друг друга по размеру.
4. Подпись у части нод ушла слишком далеко вправо.

## Воспроизведение (до правок)
- `npm run typecheck` — КРАСНЫЙ: 4 ошибки (см. ниже).
- Vite `http://127.0.0.1:5174/?fixture=1`, headless Chrome + CDP:
  - `window.__mapview` отсутствует; в консоли
    `Uncaught TypeError: this.renderer.setStyles is not a function` в `MapView.initRenderer`.
  - hover/click по центру крупной ноды не меняют `.hover-line`, `subgraphKey`, `pinnedId`.

## Корневые причины (проверено по исходникам sigma 4.0.4)
- **A. Крэш инициализации.** `mapview.ts` вызывает несуществующий `Sigma#setStyles`
  (в v4 есть `getStyles`, стили задаются только в конструкторе). Исключение прерывает
  `initRenderer()` ДО навешивания `enterNode/clickNode`, camera `updated` и dev-хука.
  Отсюда симптом 2; заодно не работает LOD и не обновляется `lodRatio`.
- **B. Размеры в экранных пикселях при отдалении.**
  `itemSizesReference: 'screen'` + `zoomToSizeRatioFunction = min(sqrt(ratio), 1)`:
  при `ratio > 1` функция даёт 1, `scaleSize(size) = size` — радиус ноды в px НЕ меняется,
  а координаты сжимаются в `1/ratio`. Относительно графа крупные хабы растут и слипаются.
  `lodScale` гасит рост лишь до пола `0.75 * size`, что недостаточно.
- **C. Перекрытия.** Укладка (`worker.ts` → `layout()`) знает только `size` = радиус ядра,
  а Sigma рисует квад `core + halo` (`nodeQuad`, до +44 px). Подписи и хитбокс тоже
  считаются по кваду. Итог: ореолы и малые сателлиты оказываются внутри крупных хабов.
  Формулы гало продублированы в `core/geometry.ts` и `ui/mapStyles.ts` и расходятся.
- **D. Подпись вправо.** Sigma v4 ставит `labelPosition: 'right'` на расстоянии
  `nodeRadius * edgeDist + labelMargin`, где `nodeRadius` = **квад** (ядро + гало),
  а видимое ядро — лишь `coreFrac` квада. Для малых нод гало больше ядра в 2+ раза,
  поэтому текст висит далеко справа от точки. `labelMargin` не является настройкой
  Settings (источник — `primitives.nodes.label.margin`, по умолчанию 5).
- **E. Красный гейт (побочно, но чинится по § Always Green):**
  `labelMargin` в `MAP_SIGMA_SETTINGS`; `downloadAsPNG` требует `Sigma` без кастомных
  дженериков; `node.color` отсутствует в `WorkerNode`; `setStyles` не типизирован.

## План (минимальные правки)
1. Убрать `setStyles`, привести типы к зелёному гейту. Стили уже переданы в конструктор.
2. Один источник истины для размера: `zoomToSizeRatioFunction(ratio) = ratio` при
   `ratio >= 1` (размер узла сжимается ровно как позиции → никакого роста/слипания
   при отдалении), `sqrt(ratio)` при приближении. Стиль `size` перестаёт зависеть от
   камеры, `lodScale` становится «реальным экранным размером» только для LOD-решений
   (альфа, видимость, кегель подписи). `lodBoost` остаётся только для плотных графов.
3. Укладка получает радиус квада (`quadOf`), а не ядра; формула гало — одна
   (`core/geometry.ts`), `mapStyles.ts` импортирует её. Сближение подписей: гало
   уменьшается до аккуратного ореола, `labelPosition: 'over'` для всех нод, где текст
   влезает в ядро, `margin` задаётся через `primitives.nodes.label`.
4. Тесты: юнит-тесты на чистые функции масштаба/гало/коллизий в `src/core/`;
   ручная верификация Sigma-слоя через headless Chrome (hover, click, zoom, скриншоты).

## Критерии приёмки
- Preflight зелёный: `typecheck && test && build`.
- В CDP: `__mapview` есть, `hoverLine` меняется при наведении, `pinnedId` и
  `.nodepanel` открываются по клику, `Esc` снимает пин.
- При двукратном отдалении экранный радиус крупной ноды уменьшается, а не растёт;
  число пар с пересекающимися квадами не увеличивается.
- Подписи малых нод начинаются вплотную к видимому ядру.

# 2026-11-12 — «меня 2085» склеивает форму другого слова

Статус: **ИСПРАВЛЕНО** (см. §4).

## Симптом (от пользователя)

Панель «ФОРМЫ КЛАСТЕРА» у слова `меня` (2085) показывает чужие формы другого слова:
`менять 15`, `меняет 7`, `меняют 4`, `меняю 1`, `меняем 1`.

## Корневая причина

`src/core/canon.ts` — суффиксный стеммер без словаря. Для глагола `менять`:

| слово | срезанный суффикс | остаток | вердикт |
| --- | --- | --- | --- |
| `менять` | `ть` | `меня` (4) | проходит охранник `остаток ≥ 4` |
| `меняет` | `ет` | `меня` (4) | то же |
| `меняют` | `ют` | `меня` (4) | то же |
| `меняю` | `ю` | `мен` (3) | охранник не пускает |
| `меняем` | `ем` | `меня` (4) | то же |

`меня` — самостоятельное местоимение с частотой 2085, и это ровно тот же остаток. Стеммер склеил
местоимение с парадигмой глагола `менять`. Проверено по исходнику: `RU_ENDINGS` содержит `ть`/`ет`/
`ют`, охранник `remainder.length >= 4` для `меня` выполняется.

Любая эвристика без словаря ломается на таких омонимах основы. Дискриминатор, который есть **в самом
корпусе**: частота самостоятельной формы. `меня` встречается в 139 раз чаще, чем `менять`; настоящая
парадигма (например `работе` → `работ`) держится в пределах единиц.

## Правка

1. `canon.ts`: `stemRu` получает необязательную карту частот форм. Если остаток — самостоятельная
   форма корпуса и встречается в `STEM_DOMINANCE = 25` раз чаще самого слова, стемминг не
   выполняется (`return word`). Параметр необязательный: без карты поведение прежнее (все старые
   тесты зелены).
2. `intern.ts`: `Intern` принимает карту частот в конструкторе и передаёт её в `canon`.
3. `tally.ts`: после токенизации корпуса один проход считает поверхностные частоты `plain`-токенов
   (кэшируется вместе с `tokenized`). `ponytail:` проход линейный по числу токенов, ~100k форм.

Порог 25 выбран из замеров: 139x у ошибочного слияния против <10x у настоящих парадигм.

## 4. Проверка

- `tests/canon.test.ts` (+4): `canon('менять', 'plain', counts) === 'менять'`, `canon('меняет', …)`, `canon('меняют', …)`
  — не `'меня'`; при этом `canon('работе', …) === 'работ'` (парадигма не доминирует и склеивается);
  без карты частот — прежнее поведение.
- `tests/tally.test.ts` (+1): сквозной прогон `PipelineCache` на синтетическом чате (30× `меня`,
  по одному `менять`/`меняет`) — у форм разные id.
- Гейт: `npm run typecheck` — 0 ошибок; `npx vitest run` — **235 passed / 2 skipped**;
  `npm run build` — ok.

## Ограничение (сознательное)

После правки глагольная парадигма `менять/меняет/меняют` распадается на отдельные редкие ноды:
общей основы ≥ 4 букв у них нет, а склеивать их обратно можно только словарём, который проектом
запрещён. Это честнее ложного слияния с частотным словом.

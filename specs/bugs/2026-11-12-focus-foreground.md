# 2026-11-12 — выделенная нода должна плавно выходить на верхний план

Статус: **ИСПРАВЛЕНО**.

## Симптом

Выделяешь слово — соседние тела остаются поверх него (и вокруг него), слово читается плохо;
переход мгновенный, обратно так же резко.

## Корневая причина

1. `depth` в `mapStyles.ts` поднимает ноду в верхний слой отрисовки только для пина:
   `g.pinActive && s.isHighlighted ? 'topNodes' : 'nodes'`. На наведении фокус остаётся в общем
   слое и рисуется в порядке графа — любое тело с большим индексом ложится сверху.
2. Тела вокруг не убираются вовсе: `dimAlpha` только ТЕМНИТ цвет (`dimTint`), но непрозрачность
   остаётся 1, поэтому сосед всё равно перекрывает слово. Это записано в комментарии стиля как
   осознанное решение («keep the body opaque so edges never shine through») — но именно оно мешает.
3. Ни подъём слоя, ни затемнение не имеют плавной хореографии: слой меняется булевым флагом.

## Правка

1. Слой: `depth = s.isHighlighted && dimAlpha > 0.9 ? 'topNodes' : 'nodes'`. Подъём происходит,
   когда фон уже затемнён (твин `dim` 100 мс), поэтому переключение слоя не читается как рывок;
   на выходе `dim` падает ниже 0.9 в первые ~10 мс и нода так же незаметно уходит обратно.
2. Гашение: тела, диски которых КАСАЮТСЯ диска фокуса, уходят в прозрачность до 20 %
   (`opacity` и альфа подписи), плавность — тот же твин `dim`, поэтому вход и выход симметричны.
   Расчёт — непрерывная функция расстояния, а не флаг на узле: при перескоке на другое слово
   гашение переезжает вместе с фокусом, без вспышек старого набора.
3. `src/core/geometry.ts` — `focusYield(distance, reach, ownRadius, dim)`: 1 вне касания,
   0.2 внутри, smoothstep между; результат клампится по нижней границе, чтобы стили
   непрозрачности не получали 0.19999999999999996.
   `MapView.focusSubgraph` публикует в граф-состояние точку и радиус фокуса
   (`focusX`, `focusY`, `focusReach`, `focusPxPerUnit`), стиль переводит расстояние в px
   тем же коэффициентом камеры — своих данных о камере стили не имеют.
4. Гашение считается ТОЛЬКО для ветки «вне эго-сети»: тела фона уходят, фан остаётся
   языком фокуса. Подпись уходящего тела гасится тем же коэффициентом.

## Проверка

Зонд `focus` в `tools/shot-shape.mjs`:

Самое «забитое» слово карты (400 слов / 859 связей, 7 тел касаются его диска),
свидетель — ближайший из них:

| величина | до правки | после |
| --- | --- | --- |
| `depth` наведённой ноды | `nodes` | **`topNodes`** |
| `depth` после ухода курсора | `nodes` | `nodes` (возврат) |
| `opacity` ближайшего касающегося тела | 0.64 (на базе) | **0.199** |
| непрозрачности всех касающихся тел | 1.0 у всех | 0.2 / 0.24 / 0.46 / 0.55 / 0.65 / 0.79 / 0.87 |
| серия на выходе (кадры) | — | 0.199 → 0.199 → 0.298 → 0.629 → 0.64 |
| `opacity` после ухода курсора | 0.64 | 0.64 (вернулась) |

Градация непрозрачностей — это и есть непрерывная функция перекрытия: тело, сидящее
на самом слове, уходит в призрак, тело на краю полосы касания остаётся почти целым.

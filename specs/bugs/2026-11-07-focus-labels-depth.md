# Баг 2026-11-07 — при фокусе пропадают все подписи, кроме центральной

Статус: **ИСПРАВЛЕНО**. Вердикт: `specs/verifications/2026-11-07-liquid-context.md`
(раздел «Баг фокуса»), скриншоты `diag1-*` (до) / `diag3-*` (после).

## Симптом
Пользователь навёлся/кликнул на слово: у соединённых нод нет текста, хотя до
фокуса подписи были видны. На скриншоте читается только слово центрального хаба.

## Воспроизведение
`node tools/shot-edges.mjs diag1 focusreal` → `hover@1` / `pin@1`.
CDP-дамп показывал парадокс: у всех активных нод
`labelVisibility:'visible'`, `shown:true`, `labelColor` с альфой 1,
но на картинке текста нет. `displayed: 9` (только эго-сеть), `restShown: 0`.

## Корневая причина (две)
1. **Sigma v4 перевыделяет буфер подписей по слоям глубины.**
   `whenState:'isHighlighted'` ставил `depth:'topNodes'`, а `applyStyleRule`
   автоматически зеркалит `depth` в `labelDepth`. Порядок слоёв
   `edges → topEdges → nodes → topNodes`: `renderWebGLLabels('nodes')` строит
   буфер для всех подписей, затем `renderWebGLLabels('topNodes')` вызывает
   `reallocate()` под ОДНУ подпись хаба и затирает весь предыдущий буфер.
   Итог — виден только текст хаба. Попытка закрепить `labelDepth:'nodes'`
   только у хаба давала обратный эффект: тело хаба рисовалось в `topNodes`
   поверх его собственной подписи.
2. **Правило `when: !isActive && !isHighlighted` намеренно ставило
   `labelVisibility:'hidden'` для всех остальных нод при `hasActiveSubgraph`.**
   То есть 140 читаемых слов общего вида исчезали при любом ховере.

## Исправление (`src/ui/mapStyles.ts`)
- Из `whenState:'isHighlighted'` убран `depth:'topNodes'` (и `labelDepth`).
  Все подписи остаются в слое `nodes` и рисуются после тел нод: буфер один,
  хаб не перекрывает свой текст, соседи не затираются.
- Добавлен `focusedLabelColor()`: неактивные подписи больше не скрываются,
  а приглушаются до `alpha · (1 − 0.55·dimAlpha)` (≈0.45 при полном фокусе).
  Активная эго-сеть по-прежнему форсирует `labelVisibility:'visible'` с альфой 1.
- `photoMode` по-прежнему скрывает чужие подписи, но теперь в снимке видны
  подписи ВСЕХ соединённых нод, а не только центральной (тот же баг буфера).

## Почему не отдельный коммит
Рабочее дерево содержит незакоммиченные правки пользователя; предыдущие раунды
также не коммитились. Баг выделен отдельным документом по `CONVENTIONS.md § Discovered Defects`.

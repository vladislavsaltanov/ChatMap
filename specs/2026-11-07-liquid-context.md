`specs/verifications/2026-11-07-liquid-context.md`).
Предыдущее: `specs/2026-11-07-legibility-focus-photo.md` (РЕАЛИЗОВАНО,

## 0. Отзыв пользователя
1. «Линии должны быть **еле еле видны** в общем виде» — прошлый раунд сделал их
   полностью невидимыми (`quiet` пол 0.015); нужен слабый, но читаемый след.
2. «При снимке выделенной ноды **остальные ноды тоже должны быть видны**» —
   `photoMode` сейчас прячет всё вне эго-сети и кадрирует только её.
3. «У еле еле видных нод текст должен быть с маленькой прозрачностью, но как
   только нода уже чуть более большая — текст виден хотя бы на 50–60%».
   То есть альфа подписи зависит от фактической видимости тела ноды, а не только
   от cameraRatio.
4. «Линии по толщине разные: редкие связи тонкие, частые — толстые» — прошлый
   раунд сделал все нити одинаково тонкими (`fil` 0.10…0.71 px). Вернуть
   широкий градиент по частоте.
5. «Они должны быть как liquid, втекать вытекать» — плавное течение вдоль ребра
   в обе стороны, «мениск» у нод, без резких импульсов/бусин.

## 1. Диагноз
| Пункт | Где |
|---|---|
| 1 | `mapStyles.ts::edgeOpacity` → `quiet = 0.015 + 0.62·reveal`; на r=1 p50 ≈ 0.002, видимых рёбер 0 |
| 2 | `MAP_SIGMA_STYLES` последнее правило `photoMode` → `visibility:'hidden'` для не-active; камера кадрирует bbox только активных узлов |
| 3 | `labelAlphaFor` даёт 1 почти всем нодам на r=1; `labelTextColorFor` не смотрит на `lodNodeOpacity` |
| 4 | `neural.ts::layerAxon` `fil = 0.10 + 0.55·s^1.3`; квад `1.6+2w+0.6b` |
| 5 | В шейдере только Gaussian-импульсы, тело нити статично по длине |

## 2. Дизайн
- **П.1**: `quiet = 0.09 + 0.56·edgeReveal(r)`. На обзоре потолок 0.09 (еле
  видный след), на сильном зуме-ин ~0.65. `spine`/`skeleton` сохраняются,
  поэтому плотные карты не превращаются в сетку.
- **П.2**: в `photoMode` не-active узлы получают `visibility:'visible'` и
  приглушённую непрозрачность, не-active рёбра — слабый след
  `min(0.07, edgeOpacity)`. Камера кадрирует не только эго-сеть:
  `focusSpan = max(1.35·egoSpan, 0.45·allSpan)`, центр — центр эго-bbox.
  Подписи эго-сети по-прежнему форсированы, чужой текст не мешает.
- **П.3**: `labelProminence(attrs,g) = 0.18 + 0.82·smoothstep(0.12,0.5,vis)`,
  где `vis = lodNodeOpacity(drawnCore(attrs), g)`. Пыль → ~0.18,
  чуть более заметная нода → ≥0.5, хаб → 1. Итоговая альфа =
  `labelAlphaFor(attrs, реальный cameraRatio) · prominence`.
- **П.4**: `fil = (0.08 + 1.55·s^1.5 + 0.10·dens·s + bead) · (1−0.5·lod)
  · (0.90+0.20·liquid) · (1+0.18·ends)`. Редкая связь ~0.1 px, частая ~1.7 px.
  Квад `2.0 + 3.4·w^1.3 + 0.6·bundle` (halfPx всегда больше `fil`).
- **П.5**: в `layerAxon` две встречные синусоидальные волны с длиной
  `mix(150,52,s)` и скоростью `mix(0.045,0.11,s)·u_motion`; они дышат толщиной
  и яркостью. `ends = |2t−1|^5` даёт «втекание/вытекание» у нод. Мягкие
  капли идут source→target и target→source; активные рёбра получают дополнительную
  быструю волну. Всё умножено на `u_motion` (нет анимации в скрытой вкладке).

## 4. Критерии приёмки
- Preflight зелёный: tsc 0, 156/156, build 0, исключений 0.
- r=1: рёбра «еле видны» (p50 ≈ 0.01…0.05, p100 ≤ 0.10), но не 0;
  видимых рёбер > 0 на всех трёх картах.
- Толщина: редкая нить < 0.2 px, частая > 1.3 px; градиент ≥ 10×.
- Подписи: у пыли альфа ≤ 0.25, у чуть большей ноды ≥ 0.5, у хаба 1.
- Снимок: видны и эго-сеть, и остальные ноды карты; 1200×900, 0 исключений.
- Hover/pin/фото-кнопка/Escape без регрессий; снимки и замеры в вердикте.

## 5. Риски
| Риск | Мера |
|---|---|
| След линий снова станет шумом | пол 0.09, сохранены `spine`/`skeleton`, CDP-замеры |
| Толстая нить обрежется квадом | квад по `w`, проверка `fil < halfPx` на крайних `w` |
| «Liquid» станет пунктиром | амплитуда волны ≤ 20% толщины, яркости ≤ 18% |
| Снимок перестанет фокусироваться | `focusSpan` ограничен сверху долей `allSpan`, эго-сеть внутри кадра |
| Новая альфа спрячет слова хабов | `prominence` = 1 при `vis ≥ 0.5`, форсированные подписи эго-сети вне правила |

## 6. Уточнения, найденные при реализации
- **Главное открытие**: одних шейдерных-uniform'ов недостаточно. `tick()` обновлял
  `u_time`, но Sigma v4 не перерисовывает канвас без `scheduleRender()` — два кадра
  CDP были побайтово одинаковы (`liquidMotion: changed:false`). Добавлен лёгкий
  рендер ~30fps (`scheduleRender()`, не полный `refresh()`), только для видимой
  вкладки; после этого `changed:true`. Без этого «liquid» был бы статичной картинкой.
- П.1: сначала пол `quiet = 0.09` дал на реальной карте лишь 28 еле различимых
  рёбер из 1212 (подавляли `spine`/`skeleton`). Добавлен **константный** след
  `trace = 0.03·(1−reveal)·(1−0.7·deepPhase)` через `max(base, trace)`: все
  1212 рёбер имеют альфу 0.03 на обзоре, p100 осталось 0.09 у топ-коридоров.
  Первый вариант с умножением на `freq` давал p50 0.01 — не читался вовсе.
- П.3: рампа `smoothstep(0.05,0.18,vis)` давала mid-нодам 0.45 (ниже требуемых
  50–60%). Сдвинута на `smoothstep(0.03,0.12,vis)`: пыль 0.18, средние 0.897,
  хабы 1.0 (реальная карта, r=1); на r=2 — 0.045 / 0.51 / 1.0.
- П.2: `photoMode` больше не скрывает не-active узлы — они видны при
  `max(0.22, lodNodeOpacity·0.5)`, чужие подписи убраны, контекстные рёбра
  `min(0.07, edgeOpacity)`. Камера кадрирует `max(1.35·egoSpan, 0.45·allSpan)`,
  поэтому на снимке видна и эго-сеть, и остальная карта.
- П.4: квад увеличен до `2.0+3.4·w^1.3+0.6·bundle`, иначе толстая нить
  обрезалась бы `halfPx`. Замер: `fil` 0.109 / 0.187 / 1.63 px (p0/p50/p100
  реальной карты) — градиент ~15×.
- П.5: амплитуда волны доведена до ±14% толщины и ±15% яркости, мениск у концов
  `+24%`; две встречные волны + капли source→target и target→source, активные
  рёбра получают третью быструю волну. Всё умножено на `u_motion`.

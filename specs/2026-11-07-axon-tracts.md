# План 2026-11-07 (третья запись) — настоящие нервные тракты, толщина и яркость по частоте

Статус: **РЕАЛИЗОВАНО** (вердикт: `specs/verifications/2026-11-07-axon-tracts.md`).
Предыдущие итерации: `specs/2026-11-07-neural-bundles-plan.md`,
вердикты: `specs/verifications/2026-11-07-neural-bundles.md` (§7 — рёбра, §8 — укладка).

## 0. Что просил пользователь
1. Линии слишком толстые даже у редко используемых связей.
2. Ориентир — референсы, особенно 3-й (FDEB / US migrations): тончайшие волоски
   слипаются в общий ствол и снова расходятся к своим нодам.
3. Линии как связи нейронов: слипаются, перетекают, где-то толще, где-то тонкие,
   где-то яркие, где-то тусклые. При уменьшении зума самые частые связи остаются
   самыми яркими, остальные тускнут по убыванию частоты.

## 1. Диагноз текущего кода
- `MAP_SIGMA_STYLES.edges[0].size` = `2.8 + 0.6w + 2.2bundle`; `bundle ≈ 1` у всех
  рёбер (3 глобальных сектора направления) → квад ~5.6 px у **каждого** ребра.
- `layer_axon`: `filament = 0.45 + 0.02·halfPx + bead` — **не зависит от веса**,
  плюс `spread` рисует вторую пару нитей у концов. Редкая связь = та же толщина,
  что и частая; яркость меняется, геометрия нет. Это ровно п.1.
- `bundleEdges()` даёт всем рёбрам сектора **одинаковую кривизну**. Линии идут
  параллельно, но не слипаются: на скриншоте `before-ratio1.png` — хаотичные
  пересечения, трактов нет. Квадратичная Безье с одним control point принципиально
  не может дать общий коридор (только точку схода).
- `opacity` рёбер = `edgeBrightness(strength) · lodTier(minNodeSize, lodRatio)`.
  LOD завязан на **размер ноды**, а не на частоту связи: при отдалении тускнут все
  рёбра одинаково, топа по частоте не остаётся. Это п.3.

## 2. Проверенные факты о Sigma 4.0.4 (исходники `node_modules/sigma`)
- `EdgePath` — расширяемый интерфейс: достаточно `path_<name>_position(t, source, target)`,
  остальное (`length`, `tangent`, `normal`, `closest_t`, `t_at_distance`) генерируется
  автоматически; `analyticalTangentGlsl` перекрывает численную касательную.
- Атрибуты пути кладутся в edge attribute texture: `size: 4, type: FLOAT,
  source: 'tract'` → varying `vec4 v_tract` (имя без префикса `a_`).
  `packAttributes()` читает массив из resolved display data; `postEvaluateEdge()`
  подхватывает `attrs[varName]`, если переменная объявлена в `primitives.edges.variables`.
- Нормализация координат — **равномерный масштаб + сдвиг** (`ratio = max(dx, dy)`),
  значит безразмерные коэффициены `(u, v)` от `(delta, perp)` инвариантны к камере
  и к экстенту графа. Абсолютные world-координаты в атрибут класть нельзя.
- `alpha = smoothstep(aaWidth, -aaWidth, ctx.sdf) · v_opacity`: за пределами квада
  рисовать нельзя. Значит `size` (квад) должен вмещать нить + `spread` + ореол.
- `v_opacity` применяется один раз к результату слоя → яркость по частоте и LOD
  держать в `MAP_SIGMA_STYLES.edges.opacity`, а не запекать в альфу шейдера.

## 3. Решение

### 3.1 `src/core/geometry.ts` — FDEB-лайт, чистые функции
`bundleEdges(points, edges, maxWeight?) → BundleInfo[]`, где
`BundleInfo = { tract: [u1,v1,u2,v2], bundle: number }` (`bundle` = плотность тракта 0..1).

1. Для каждого ребра: `p1`, `p2` в точках 1/3 и 2/3 хорды, направление `θ mod π`,
   `strength = weight / maxWeight`.
2. Два прохода mean-shift: ключ группы = `(сектор θ из 6, ячейка mid(p1,p2)/cell)`,
   `cell = 1.6 · median(len)`. В группе ≥2 рёбер считаются центроиды `p1` и `p2`
   с весом `0.5 + 0.5·strength` (частые связи задают ось тракта).
   `pull = (0.62 | 0.38) · density · (1 − 0.4·strength)`; `density = min(1, (n−1)/6)`.
   P1 тянется к центроиду P1, P2 — к центроиду P2 ⇒ образуется **коридор**, а не точка.
3. `C1 = 3P1 − 1.5P2 − 5/6·A + 1/3·B`, `C2 = 3P2 − 1.5P1 − 5/6·B + 1/3·A`
   (кубическая Безье точно проходит через P1/P2 при t=1/3, 2/3).
4. `u = dot(C−A, d)/|d|²`, `v = dot(C−A, perp)/|d|²`, `perp = (−dy, dx)`;
   clamp `u ∈ [−0.1, 1.1]`, `v ∈ [−0.35, 0.35]`. Прямое ребро = `[1/3, 0, 2/3, 0]`.
5. Одиночные рёбра, отсутствующие позиции, нулевая длина → прямой tract, `bundle = 0`.
   Детерминизм: никакого `Math.random`, только арифметика и хэш индекса.

Сложность O(E) на проход (без O(E²)) — важно при `cap = 3.5·N` рёбер.

### 3.2 Проводка данных
`BundleEdgeInput` += `weight`; `WorkerEdge`: `curvature` → `tract: [4]`, сохранить
`bundle`. `worker.ts` передаёт `selection.maxWeight`. `mapview.ts` кладёт `tract`
в атрибуты ребра, `size = 1.4 + 3.0·strength^1.3 + 1.4·density` (квад под нить),
`strength = edgeWidth(w, wmax)`, `lodSize` сохраняем для мягкого dust-фактора.

### 3.3 `src/ui/neural.ts` — свой путь + переписанный аксон
- `pathTract()` (`EdgePath`, 18 сегментов): кубическая Безье по `v_tract`,
  аналитическая касательная, `path_tract_length` 8 сэмплов.
  `NEURAL_PRIMITIVES.edges.paths = [pathTract()]`, `variables.tract`.
- `layer_axon`: толщина нити `w = 0.20 + 1.05·strength^1.3 + 0.20·bundle + bead`
  (редкая ≈ 0.2 px радиуса = волосок, частая ≈ 1.4 px). `spread` только у
  плотных трактов (`bundle · min(halfPx·0.5, 1.15) · |2t−1|^1.5`), ореол ≤0.09,
  импульс больше не расширяет тело (`pulse · body`). Цвет к белому по `strength`.

### 3.4 `src/ui/mapStyles.ts` — яркость по частоте + контраст при зуме
```
tier(s, ratio) = 0.06 + 0.94 · s^(1 + 2.4·zoomOut)
zoomOut        = clamp((lodRatio − 1)/2.4, 0, 1)
opacity        = tier · (0.6 + 0.4·lodTier(minNodeSize, lodRatio)) · (1 − 0.93·dim)
active         = min(1, tier + (1 − tier)·focusAlpha)
```
Монотонно по `s`: при отдалении топ-связи остаются ≈1, остальные убывают по частоте.
`path: 'tract'` вместо `'curved'`, `curvature` → `tract`.

### 3.5 Тесты (`tests/geometry.test.ts`)
Детерминизм; прямой tract у одиночного ребра; clamp `u/v`; у группы «веер» tract
control points ближе друг к другу, чем исходные хорды ( numeric-проверка слияния );
`bundle` растёт с размером группы; отсутствующие/вырожденные рёбра безопасны.

## 5. Риски
| Риск | Мера |
|---|---|
| `vec4`-атрибут пути не подхватится Sigma | проверка CDP в п.4; откат — квадратичная Безье с `curvature`, посчитанным через общий якорь |
| Слишком сильный изгиб → петли | clamp `v ∈ [−0.35, 0.35]`, 18 сегментов |
| Слипание в одну линию без текстуры | `pull < 1`, сильные рёбра тянутся слабее, остаются отдельные волоски |
| Регрессия подписей / hover / коллизий | не трогаем `graph.ts`, `labels.ts`, `subgraphHighlight.ts`; CDP-регрессия |
| Производительность | O(E) вместо O(E²), без новых зависимостей, всё тяжёлое в воркере |

Данные чата не покидают браузер. Коммит — только по явной команде.

## 6. Уточнения, найденные при реализации
- Группировка «направление + ячейка от median(len)» собрала **все 535 рёбер** в один
  тракт (median-длина сопоставима с экстентом графа) → глобальные дуги. Заменено на
  локальные тракты `hub:сектор` (8 секторов по 2π, округление индекса для seam 0/2π)
  плюс третий проход «параллельные соседи» с ячейкой `span/8`. Итог: 521 / 535 рёбер
  в трактах, медиана изгиба 0.141, максимум 0.6 (clamp `|v| ≤ 0.3`).
- P1/P2 ориентируются от хаба к цели; если хабом оказался `b`, контрольные точки
  меняются местами — иначе кривая переворачивалась.
- Добавлены детерминированные «полосы» (`lane = hash(i) − 0.5`, сдвиг ⟂ к оси тракта),
  чтобы пучок читался отдельными волосками, а не одной жёсткой прямой.
- `spread`/веер в шейдере убран полностью: он рисовал вторую пару нитей у концов и
  был главным источником «толстых редких связей». Разлёт теперь геометрический.
- `bundle` участвует в толщине только как `0.15·dens·s` (не поднимает редкие связи);
  `fil = 0.18 + 1.15·s^1.3 + 0.15·dens·s + bead`.
- Яркость: `0.16 + 0.84·s^(1 + 1.6·zoomOut)`, dust-фактор ослаблен до
  `0.85 + 0.15·lodTier` — топ-связи остаются яркими и на глубоком зуме.
- `phase = phaseFor(a ^ b)` на ребре: импульсы перестали идти синхронно.
- Проверено в исходниках Sigma 4.0.4: `vec4`-атрибут пути (`a_tract`, source `tract`)
  доезжает до шейдера как `v_tract` через `postEvaluateEdge` + edge attribute texture;
 自定义的 `pathTract()` работает без ошибок компиляции шейдеров.

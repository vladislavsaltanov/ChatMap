# План 2026-11-07 — разделение подписей, неоднородная укладка, LOD, hover-текст, нейронные пучки

Статус: **ПРОДУМАННАЯ ВЕРСИЯ (вторая запись)**. Первая запись была черновиком до анализа кода;
файл перезаписан после чтения `specs/`, исходников Sigma 4.0.4 и замеров в headless Chrome.

## 0. Что просил пользователь
1. Разделение текстов у разных нод рядом чуть посильнее, а то накладываются.
2. Распределение сильнее; фигура распределения по плоскости более неоднородная: где-то ближе к середине, где-то дальше, где-то форма загибается.
3. Из-за п.2 текст сильнее виден на более ранних этапах LOD, но слегка.
4. Текст появляется у нод под мышкой (если LOD позволяет).
5. Объединить линии, чтобы выглядели именно как нейроны — пучок развивается.

## 1. Что выяснено при продумывании (закрытые вопросы черновика)

**Главная находка по п.1.** В Sigma v4 `labelVisibility` имеет три значения: `auto | visible | hidden`.
`visible` = **форсированная** подпись: `hasForcedLabel(data)` = `labelVisibility === 'visible' && visibility !== 'hidden'`,
такие узлы добавляются в `nodesWithForcedLabels` и **обходят `LabelGrid` и `labelRenderedSizeThreshold`**.
Сейчас `mapStyles.ts` ставит `labelVisibility: 'visible'` всем нодам → `labelDensity: 4` вообще не работает.
CDP-замер: при ratio 1 показано 17 подписей, `forced: 17, auto: 0`; при ratio 0.44 — 28 подписей, 1 пересечение.
На реальном чате (topN 600) форсированных подписей сотни → наложения. Лечение: базовые подписи → `auto`,
а `visible` оставить только для форсирования по наведению.

**Формула `LabelGrid` (sigma.esm.js:2707):** `labelsPerCell = ceil(density / ratio²)`, ячейка `labelGridCellSize`.
Кандидаты в ячейке сортируются по `data.size` по убыванию → побеждают крупные ноды.
Значит «сильнее разделить» = уменьшить `labelDensity` и/или увеличить `labelGridCellSize`, а не наоборот.

**П.4 — легальный способ есть.** Отдельного `forceLabel` в стилях нет: `NodeDisplayData.forceLabel`
вычисляется из `labelVisibility === 'visible'`. `setMembership(nodesWithForcedLabels, ...)` обновляется при
пересчёте display data узла (в т.ч. при `setNodeState`) → hover сам обновляет форсирование. `forceLabel`
не надо трогать руками.

**П.5 — `EdgeContext` и `pathCurved`.** `pathCurved` строит квадратичную Безье:
`control = midpoint + perp(-dy,dx)/len * curvature * len`; `curvature` — доля длины ребра.
Сейчас `edgeCurvature(a,b)` — случайный знак/величина из хэша → «спагетти».
`ctx.sdf + ctx.thickness*0.5` = `distFromCenter`, в пикселях это `dPx`; `v_side` знак теряется,
поэтому `abs(dPx - offset)` даёт симметричные филаменты по обе стороны от осевой — ровно то, что нужно для пучка.
Квад ребра по ширине равен `data.size`, поэтому чтобы нарисовать несколько филамент, надо **расширить `size`**
(иначе их обрежет геометрия), а тонкие нити рисовать внутри квада слоем `layerAxon`.

**П.2 — ограничение `autoRescale`.** Простое увеличение world-отступов/span не меняет экранную плотность:
Sigma подгоняет экстент под вьюпорт, `screenDist = D * V/E`, и при пропорциональном росте D и E дистанция стоит на месте.
Работает только изменение **отношений**: радиальная неоднородность, секторные карманы, закрутка, пустоты вокруг хабов.
Поэтому новая логика — деформация плоскости после нормализации и до `resolveCollisions`.

**Ограничения тестов** (`tests/graph.test.ts`): 2–3 узла, `iterations: 0`, детерминизм, «сильная связь ближе»,
`void > 0.05`, `overlap < 5%` на 600 узлах, «центр разрежен» (<60 в ±500), `maxR/p90 < 3`,
клиренс хаб/сателлит `(60+s)*8`. Новую деформацию применяем только при `order >= 8` и `iterations > 0`,
амплитуды держим умеренными, коллизии после деформации — клиренс сохраняется.

**Базовые метрики (до работы):** Preflight зелёный (134 теста); пересечения ядер 0, квадов 2 на 528 парах
при ratio 1..3.375; подписи 17/28 форсированных, 0/1 пересечений.

## 2. Принятые допущения (важно для п.5)
«Пучок развивается» читаем как **единый нервный тракт**: рёбра одного хаба сходятся к общей контрольной точке,
затем расходятся веером, внутри тракта видно несколько филамент, которые по ходу `t` проявляются/расходятся.
Это НЕ возврат к отклонённому стилю «пауки / дендриты от каждой ноды» (`specs/heatmap-obsidian-nodes.md`):
отростков и ветвлений от сомы нет, узлы остаются чистыми дисками. Пучок растёт от источника к цели
(`spread(t)` = 0 у источника, максимум к цели, лёгкое сужение на самом конце, без раструбов).

## 3. План по пунктам

### П.1 Разделение подписей — `src/ui/mapStyles.ts`, `src/ui/mapview.ts`
- Базовый стиль и `when` (неактивные): `labelVisibility` → `auto` вместо `visible`; `hidden` сохраняется
  при `labelAlphaFor <= 0.02` и при `hasActiveSubgraph`.
- `MAP_SIGMA_SETTINGS`: `labelDensity: 4 → 2`, `labelGridCellSize: 128 → 160`.
  Крупные ноды выигрывают в ячейке, мелкие рядом с ними уходят → «чуть посильнее» без облысения карты.
- Проверка CDP: `forced` без ховера = 0, `auto` > 0, число пересечений боксов не больше базового
  (на фикстуре 0/0, при zoom 0.44 ≤1). Если на плотном графе останутся наложения — добавить чистый
  `resolveLabelBoxes()` в `src/core/` с приоритетом по размеру и зазором 4px (план-Б, только по замеру).

### П.2 Неоднородная усиленная укладка — `src/core/graph.ts`
- Новая экспортируемая чистая функция `warpPlane(points, phases)`: мутирует `x/y`.
  - секторные карманы: `pocket = shapeNoise(angle, phases)` → радиус `1 + 0.25*pocket`;
  - радиальная волна: `0.12*sin(3a+p) + 0.06*sin(5a+p)`;
  - загиб/закрутка: `a' = a + 0.25*u^1.4*sin(...) + 0.18*shapeNoise(2a+u, phases)*u`;
  - лёгкий контраст плотности `u^1.05`, `u` зажат сверху `1.06` (чтобы не сломать `maxR/p90 < 3`).
- `shapePhases`: 8 → 10 фаз из того же `createRng(seed)` (детерминизм сохраняется).
- Вызов в `layout()` после нормализации к `targetSpan`, до `resolveCollisions`, только при
  `iterations > 0 && graph.order >= 8`.
- Усиление локальных пустот: `padScale` в `layout()` `max(16, sz*0.85+10)` → `max(20, sz*1.15+12)`.
- Тесты (`tests/graph.test.ts`): детерминизм warp, ограниченность смещения, рост разброса радиусов
  (неоднородность), угол меняется (загиб), `order < 8` не деформируется.

### П.3 Чуть более ранний LOD текста — `src/ui/mapStyles.ts`
- `labelAlphaFor`: small-ветка `(0.95 - r)/0.65 → (1.02 - r)/0.68`, порог `(12-size)/12 → (12-size)/13`;
  medium-ветка `lodRatio > 1.15 → 1.20`; fadeguard центрированных `(rendered-10)/8 → (rendered-8)/8`.
- Сдвиг на одну ступень, без отмены LOD; `zoomToLabelSizeRatioFunction` остаётся согласованным с нодами.

### П.4 Текст под мышкой — `src/ui/mapStyles.ts`
- `whenState: 'isHighlighted'` (центр эго-подграфа, ставится `SubgraphHighlight.swap`) →
  `labelVisibility: (attrs,_s,g) => renderedNodeSize(drawnCore(attrs), g.lodRatio) >= 6 ? 'visible' : 'hidden'`
  и `labelColor` с альфой 1. Условие `>= 6` и есть «если LOD позволяет» (пыль при отдалении не форсируется).
- `whenState: 'isActive'` (соседи) → `auto`, чтобы ховер не выплёвывал сразу 9 форсированных подписей.
- Проверка CDP: при наведении `shown` содержит ключ, `forced` = 1, подпись видна; при уходе — снова `auto`.

### П.5 Пучки — `src/core/geometry.ts`, `src/core/types.ts`, `src/core/worker.ts`, `src/ui/mapview.ts`, `src/ui/neural.ts`, `src/ui/mapStyles.ts`
- `bundleEdges(points, edges)` в `src/core/geometry.ts` → массив `{ curvature, bundle }` по индексу ребра:
  1. degree по рёбрам; хаб = конец с большей степенью (при равенстве — меньший id);
  2. группа по хабу; якорь `A = hub + perp(meanDir)*0.30*meanLen + meanDir*0.25*meanLen`;
  3. `curvature = clamp(dot(A - midpoint, perp_unit(a→b)) / len, -0.35, 0.35)` — все рёбра группы
     сходятся к одному якорю («объединить линии»);
  4. `bundle = min(1, (groupSize-1)/3)`, одиночные рёбра → 0.
  Всё детерминировано (`phaseFor` / арифметика), без `Math.random`.
- `WorkerEdge` += `curvature`, `bundle`; `worker.ts` считает их по `posList`+`backboneEdges` и шлёт в `map`.
- `mapview.ts`: убрать `edgeCurvature(a,b)`, брать `edge.curvature`; `size = 1.4 + 1.4*w + 4.2*bundle`
  (ширина квада под филаменты), добавить атрибут `bundle`.
- `MAP_SIGMA_STYLES.edges`: переменная `bundle` из атрибута; `NEURAL_PRIMITIVES.edges.variables.bundle`.
- `layerAxon`: вместо одного сплошного тела — пучок филамент:
  `grow = smoothstep(0,0.4,t) * (1 - 0.3*smoothstep(0.8,1,t))`,
  `spread = bundle * min(halfPx*0.62, 3.0) * grow`,
  `d = min(|dPx|, |dPx-0.55*spread|, |dPx-spread|)`, радиус филаменты ~0.9px + `bead`;
  сохранить градиент `sourceColor→targetColor`, glow, импульсы `u_time`. Никаких дендритов/раструбов.
- Тесты: детерминизм, `|curvature| <= 0.35`, control points группы ближе к якорю, чем случайная кривизна,
  одиночное ребро `bundle = 0`, климпинг.

## 4. Порядок реализации
1. `npm run typecheck && npm run test && npm run build` — подтвердить зелёную базу.
2. П.1 → тесты + CDP-замер подписей. 3. П.2 → тесты `graph.test.ts` + замер формы/пересечений.
4. П.3 → тесты + замер LOD. 5. П.4 → тесты + CDP hover. 6. П.5 → тесты + скриншоты пучков.
После **каждого** шага: `typecheck && test`, в конце полный Preflight. Код только после этой записи плана.
Никаких новых зависимостей; тяжёлые вычисления остаются в воркере; данные чата не покидают браузер.

## 5. Критерии приёмки
- Preflight зелёный, тестов ≥ 137, исключений в консоли 0.
- Подписи: без ховера `forced = 0`; пересечений боксов ≤ базовых (0 при r=1, ≤1 при r=0.44);
  hover → ровно одна форсированная подпись, она реально видна; при сильном отдалении пыль не форсируется.
- Укладка: разброс радиусов/углов вырос относительно базового дампа, на скриншоте видны карманы и загиб;
  пересечения ядер нод по-прежнему 0 при ratio 1, 1.5, 2.25, 3.375.
- LOD: подписи появляются на одну ступень раньше, но при 3.375 по-прежнему гаснут.
- Пучки: на скриншоте рёбра одного хаба сходятся в тракт и расходятся филаментами; нет «пауков»,
  нет раструбов у нод; FPS/производительность не деградирует визуально.
- Вердикт и скриншоты → `specs/verifications/2026-11-07-neural-bundles.md`.

## 6. Риски и откат
| Риск | Мера |
|---|---|
| `auto` спрячет слишком много подписей | density/cell подбираются по CDP-замеру; hover форсируется |
| warp вернёт перекрытия ядер | коллизии идут ПОСЛЕ warp; замер 528 пар; амплитуды уменьшаются при провале |
| warp сломает тесты (i)/(j)/(k) | `order >= 8`, cap `u <= 1.06`, умеренные амплитуды; тесты после шага |
| широкий квад ребра даёт артефакты | `size <= 7px`, `curvature` климпинг, филаменты внутри `halfPx` |
| смена `WorkerEdge` ломает типы | правим `types.ts`, `worker.ts`, `mapview.ts` одной правкой, typecheck |
| «пауки» вместо пучка | нет ветвлений от сомы, только симметричные филаменты внутри тракта; сверка со скриншотом |

## 7. Уточнения, найденные при реализации (после второй записи плана)
- **П.1**: одного перехода на `auto` оказалось мало — при сильном зуме-ин
  `labelsPerCell = ceil(density / ratio²)` снова разрешал почти все подписи, оставалось
  1 пересечение. Добавлен чистый `resolveLabelBoxes()` (`src/core/labels.ts`) с
  пространственным хэшем и зазором 4 px; результат кладётся в `graphState.labelBlocked`
  на каждом изменении камеры (один `refresh`, без обратной связи через display data).
  Итог: 0 пересечений при ratio 1 / 0.67 / 0.44, показано 14 / 18 / 27 подписей.
- **П.2**: первая амплитуда `warpPlane` давала почти круг. Усилено до 3–5 лопастей
  (`arm`), спирального сдвига `0.38*u^1.25`, карманов и радиальной волны; cap `u <= 1.35`.
  `padScale` → `max(26, sz*1.3+14)`, проходов коллизий 140 для малых графов:
  пересечения ядер снова 0 при всех уровнях зума, разброс радиусов вырос (CV 0.428→0.439,
  max 4221→5274), на скриншоте видны лопасти, пустоты и загиб.
- **П.5**: группировка «по хабу + общий якорь» не сходилась на звёздчатом графе
  (контрольные точки разных направлений не могут лечь в одну точку) и давала всего
  2 пучка из 28 рёбер. Заменено на группировку **по направлению** (3 сектора, угол по
  модулю π): рёбра одного тракта получают общую кривизну + мизерный джиттер, поэтому
  линии перестают хаотично пересекаться и «объединяются». Пучок рисуется на каждом
  ребре: толстый ствол у сомы (`filament = mix(1.35, 0.62, grow)`) разворачивается в
  3 филамента (`d = min(dPx, |dPx - spread|)`, `grow = smoothstep(0.05, 0.45, t)`).
  Квад ребра расширен до ~8 px, иначе филаменты обрезаются геометрией. Дендритов,
  раструбов и «пауков» нет — это единый нервный тракт.
- **П.5, вторая правка по отзыву пользователя**: замысел был противоположным — линии
  **смыкаются в одну по пути**, а **расплываются только у концов к своим нодам**.
  Профиль изменён на `fan = |2t−1|^1.6`, квад уменьшен до ~5 px, добавлена яркость
  по весу связи (`strength` → `opacity` и белый hot-core в шейдере). Подробности и
  замеры — раздел 7 вердикта.
- **Доп. правка укладки**: по просьбе пользователя добавлены горизонтальная анизотропия
  (`PLANE_STRETCH_X/Y`), фрактальный шум `fractalNoise()` с domain-warp и дискретными
  разломами, увеличенные зазоры (`MAX_SCALE_FACTOR 10`, `padScale`, `stagePadding 28`),
  warp только на `fullRun`. Замеры и скриншот — раздел 8 вердикта.

Коммит не создаётся без явной команды: в рабочем дереве уже есть незакоммиченные правки пользователя.

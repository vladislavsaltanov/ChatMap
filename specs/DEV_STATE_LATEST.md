Архитектурные факты, добытые по ходу (важно не потерять):
- Sigma v4: `depth` переносит элемент между бакетами **без reprocess**, `zIndex` — **с reprocess**.
- **Подписи нельзя разносить по двум depth-бакетам**: буфер подписей пересобирается на каждый
  проход, и проход `nodes` целиком пропадает из пикселей (54 подписи «displayed» → 0 пикселей).
  Поэтому `labelDepth` — константа `'topNodes'` для всех нод.
- Зазор коллизий задаётся в **экранных** px и переводится в мир тем же коэффициентом, что позиции
  (`pxToWorld = targetSpan / 1300`); абсолютный зазор в мировых единицах насыщает упаковку.

## 3. Открытые задачи

### 3.1. Блокер релиза: работа не закоммичена
13 изменённых файлов и 4 новых лежат в рабочем дереве на `feat/ponytail-audit-fix`.
Нужно решить формат: один коммит или серия по задачам (проект исторически коммитит по задаче:
`fix(core): …`, `perf(graph): …`). Пока не закоммичено — любой `git checkout`/`stash` уносит
850 строк правок.

### 3.2. Остаточное мерцание подписей (16 из 250)
Полностью не закрыто. Оставшиеся случаи — подпись освобождается от коллизии и через 2–4 шага
вытесняется выросшей плотностью (непрерывное окно, не стробоскоп). Полное решение потребует либо
временного затухания при смене решения блокировки, либо монотонной по зуму раскладки.
Воспроизведение: `node tools/shot-shape.mjs flick 400 2000 271`, блок `"flicker"`.

### 3.3. Сложность `layout()`
`src/core/graph.ts`: cc 64 (до работы было 53). Контурный блок (осевое растяжение + угловой шум +
выталкивание лобов) — очевидный кандидат на вынос в `sculptContour()`. Покрыт тестами
`(g)/(h)/(j)` в `tests/graph.test.ts`.

### 3.4. Стоимость эго-веера на реальном большом чате
Наведение на хаб пишет `degree` состояний рёбер и `degree` состояний узлов (165+166 на хаб из
271-нодовой синтетики). Замерено только на синтетике 250–1000 нод; на реальном чате 1500+ слов с
хабом степени 300+ не профилировалось. Если просядет — ярус считать формулой в стиле, а не хранить
в состоянии.

### 3.5. Экспорт PNG не перепроверен
`photoMode` использует `egoTier`/`plateAlphaFor`/`promote`. После правок фокуса и плашек снимок
ноды и PNG-экспорт визуально не проверялись. Проверять: кнопка PNG на карте и «Фото» в панели ноды.

### 3.6. UI-слой без юнит-тестов
219 тестов покрывают `src/core/`. Раскладка подписей, ярусы веера, промоушен пина проверяются
только пробами в `tools/shot-shape.mjs` (`census`, `fan`, `flicker`, `sweep`). Это одноразовый
стенд, а не автотесты — регрессия в UI-слое ловится только глазами.

### 3.7. `tools/shot-shape.mjs` не в репозитории
Единственный воспроизводимый стенд визуальной проверки (синтетический чат → карта → метрики →
скриншоты → пробы). Нужно решить: коммитить (как остальные 4 файла в `tools/`) или удалять.

### 3.8. Не подтверждено на живом чате
Все замеры — на синтетике (2 генератора: топологический стенд в `tests/bench-tmp-shape.test.ts`
и браузерный в `tools/shot-shape.mjs`). Пользователь проверяет на своём экспорте.

**Предел, который надо помнить:** на 1000 нод на полотне 1400×900 «воздушные зазоры» и «плотные
кластеры» несовместимы — 1000 тел на 41 px среднего шага. На этом масштабе выигрыш в *видимости*
(было скрыто 226 нод, стало 0), а кластерность метрически не улучшилась (стенд 0.83 → 0.82).

## 4. Как проверить всё с нуля

```bash
npm run typecheck && npx vitest run && npm run build     # гейт
npm run dev                                              # dev-сервер (порт 5173)
node tools/shot-shape.mjs <tag> <vocab> <messages> <topN>
#   примеры: 400 2000 271 (малый чат), 900 4000 600, 1400 6000 1000
#   вывод: метрики формы (clarkEvans, screenSize, hidden, labels), пробы
#   "pin" (глубина пина), "enter" (стаггер входа), "filter" (круговой прогон фильтра),
#   "fan" (ярусы веера), "census" (подписи при пине), "flicker" (мерцание по зуму)
#   скриншоты: tests/betterwright/shape/<tag>-*.png
CHATMAP_DPR=1.25 node tools/shot-shape.mjs …              # воспроизвести дробный DPR
```

Замечание по окружению: dev-сервер на `127.0.0.1:5173` уже запущен отдельным процессом —
фоновый `npm run dev` падает с `Port 5173 is already in use`, это ожидаемо.

## 5. Что нельзя ломать (инварианты из работы)

1. Данные чата не покидают браузер; тяжёлое — в воркере, main рисует.
2. Все подписи — в одном (последнем) depth-бакете; разнесение по бакетам молча убивает отрисовку.
3. Зазор коллизий — в экранных px, через `pxToWorld`; абсолютные мировые константы запрещены
   (они превращают карту в решётку).
4. Переиспользование кадра при обновлении фильтра: без FA2 и без повторной нормировки, иначе
   силуэт разрушается на любом переключателе.
5. Плашка подписи гаснет вместе с текстом (`plateAlphaFor`) — иначе пустая рамка.

## 1. Что изменилось визуально
| | До | После |
|---|---|---|
| Тело | диск ровно цветом пластины = «дырка» | углублённая линза: оттенок автора у края, центр почти пластина |
| Контур | 1 px, тихий | 1 px, теплее и ярче + уникальная дуга ~75° по `phase` узла |
| Ядро | одна белая точка | точка + 4-лучевой крест + шёпот света |
| Глубина | одно внутреннее кольцо | внутренний лимб, фаска, 12 градуировок |
| Свет | нет | tight-ореол цвета автора, α ≤ 0.16 (≤ 0.38 на фокусе) |
| Фокус | только яркость кольца | + второй контур-ретикл на 2.8 px, усиление ореола и дуги |
| Нити | 0.67 px у фоновых связей | 0.94 px (+41 %); магистрали 3.26 → 3.42 px (+5 %) |

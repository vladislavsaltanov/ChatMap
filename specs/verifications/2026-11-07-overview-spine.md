## 1. Двухступенчатый LOD: масштаб → быстрая прозрачность
Все фазы считаются по **реальному** `cameraRatio`; `lodRatio` с density-бостом
оставлен только за подписи. Агрессивность масштабируется
`mapDensity = clamp((order − 50)/350, 0, 1)`.

| cameraRatio | видимых рёбер (opacity>0.05) | размер ноды p0 / p50 / p100 | opacity p0 / p50 / p100 |
|---|---|---|---|
| 0.32 (зум-ин) | 891 | 8 / 11 / 47.98 | 0.004 / 0.189 / 1 |
| 0.55 | **885** | **4.85** / 7.33 / 47.98 | 0.003 / 0.176 / 1 |
| 1.00 (обзор) | **142** | **0.96** / 2.81 / 47.98 | 0 / 0.004 / 1 |
| 2.20 | 38 | 0.96 / 2.81 / 47.98 | 0 / 0 / 1 |
| 3.40 | 21 | 0.96 / 2.81 / 47.98 | 0 / 0 / 1 |

Ключевая строка — r=0.55: все 885 рёбер ещё на месте, но малые ноды уже сжались
с 8 до 4.85 px. **Масштаб отработал первым**, прозрачность включается только на
коротком участке 0.82→1.05. Хабы (p100 = 47.98) не меняются ни на одном зуме.

## 2. Пункт 1 — рёбра гаснут вместе со своими нодами
`ends = 0.10 + 0.90·smoothstep(0.6, 5.5, rendered)`, где `rendered` — фактический
экранный радиус `min`-конца с учётом `lodNodeScale`. Рёбра к растворившейся пыли
теряют до 90% яркости; пол 0.10 оставляет читаемый след. Белые «слитки» у хаба
«меня» исчезли.

## 3. Пункт 2 — маленькие ноды
`lodNodeScale = 1 − 0.88·smallness·scalePhase`, `smallness = clamp((18−core)/13)`.
На обзоре малая нода 5 px → 0.96 px (было ~8 px), при зуме-ин возвращается к 8 px.
Хабы ≥18 px не сжимаются. На малой карте подавление выключено (`mapDensity = 0`):
28/28 рёбер, ноды 7.16 px, opacity p50 0.863 — регрессии нет.

## 4. Пункт 3 + «пути не склеиваются»
- `bundleEdges()`: проход 0 строит **общую ось** хаба (все волоски уходят по одному
  среднему направлению, каждый со своей длиной), проходы 1–2 доминируют и сливают
  параллельные рёбра разных хабов в коридор. Ограничение
  `|C − C_straight| ≤ 0.26·len` убрало изломы кубической Безье.
- `rank` — позиция волоска в тракте по весу; `tractRank` — ранг целого коридора.
  На обзоре выживает скелет из немногих трактов, а не по одной случайной линии
  от каждого: `skeleton = 1 − fade·smoothstep(6,22,tractRank)`,
  `spine = 1/(1 + rank·(0.16·mapDensity + 0.35·fade))`.
- `isolated` гасит разбросанные одиночки, `freq` держит топ по частоте самым ярким
  (`0.14 + 0.86·s^(1+3·deepPhase)`).
- Толщина нити и ореол тоже уходят на этапе масштаба (`lod`-атрибут шейдера:
  `fil ×= 1 − 0.5·lod`, `glow ×= 1 − 0.6·lod`), квад рёбер `× (1 − 0.3·lod)`.
  Небольшой всегда-включённый пол `spine` не даёт пучку выгореть в белую полосу
  при сильном приближении.

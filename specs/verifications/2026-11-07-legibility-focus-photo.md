## 5. Тихие тонкие линии (п.5)
`edgeReveal = 1 − smoothstep(0.42, 0.85, r)`, `quiet = 0.015 + 0.62·edgeReveal`.

| cameraRatio | opacity p0 / p50 / p100 (реальная) | Видимых рёбер (>0.05) |
|---|---|---|
| 1.00 | 0 / 0 / 0.015 | **0** |
| 2.00 | 0 / 0 / 0.015 | **0** |
| 3.40 | 0 / 0 / 0.015 | **0** |
| 0.32 (сильное приближение) | 0 / 0.013 / 0.635 | 71 |

При ховере/пине активные рёбра всё равно яркие (opacity 1, `brightEdges` 8/12) —
это второй разрешённый способ появления. Толщина нити ≤ ~0.7 px, glow ×0.4,
квад 1.6…4.2 px, `minEdgeThickness 0.6`, активный `+0.35` вместо `+0.8`.

## 1. Толщина по частоте (п.1 просьбы)
Было: квад `2.8+0.6w+2.2bundle` ≈ 5.6 px у **каждого** ребра, `filament` в шейдере
не зависел от веса, плюс веер из второй пары нитей у концов.
Стало: квад `1.4 + 3.0·strength^1.3 + 1.4·bundle` (1.4…5.8 px), одна нить на ребро,
`fil = 0.18 + 1.15·strength^1.3 + 0.15·bundle·strength + bead`.

| `strength` | радиус нити | ширина линии |
|---|---|---|
| 0.087 (редкая, фикстура) | ≈ 0.24 px | ≈ 0.5 px — волосок |
| 0.429 (медиана, плотная) | ≈ 0.60 px | ≈ 1.2 px |
| 1.0 (частая) | ≈ 1.48 px | ≈ 3.0 px — артерия |

CDP: `d.strength` и `d.bundle` реально доезжают до display data (`1 / 1`,
`0.948 / 1`, …), то есть шейдер получает частоту, а не константу.
Скриншот `final2dense-zoomin.png`: редкие связи — тусклые волоски, частые — белые стволы.

## 2. Слипание / перетекание (п.2, референс 3 — FDEB)
- `bundleEdges()` в `src/core/geometry.ts`: группировка `hub:сектор` (8 секторов),
  два прохода mean-shift по точкам 1/3 и 2/3, третий проход — параллельные соседи
  с ячейкой `span/8`; детерминированные «полосы» внутри тракта.

  аналитическая касательная, 18 сегментов. Квадратичная Безье с одним control point
  давала только точку схода, не коридор.

## 3. Яркость по частоте и LOD (п.3)
`edgeFrequencyTier = 0.16 + 0.84·s^(1 + 1.6·zoomOut)`, `zoomOut = clamp((lodRatio−1)/2.4, 0, 1)`.
Было: LOD завязан на **размер ноды**, при отдалении тускли все рёбра одинаково.

| Зум | opacity p0 / p50 / p100 (плотная) | Топ-3 по частоте |
|---|---|---|
| 1.0 | 0.323 / 0.520 / 1.000 | 1.000 / 0.956 / 0.953 |
| 2.2 | 0.187 / 0.305 / 1.000 | 1.000 / 0.895 / 0.918 |
| 3.4 | 0.154 / 0.224 / 0.917 | 0.917 / 0.791 / 0.838 |

Монотонно по частоте на всех уровнях зума: топ остаётся самым ярким, остальные убывают по
убыванию частоты. Для сравнения, до правки p0/p50/p100 было 0.08 / ~1.0 / 1.0 и
зависело от размера ноды, а не от веса связи.
Также цвет частых связей уходит к белому (`mix(base, 1.0, 0.75·s)`), редкие сохраняют
оттенок автора; ореол ≤0.105, импульс больше не расширяет тело нити.

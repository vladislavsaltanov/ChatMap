# План: доли вместо ровного облака (структура «нейронной сети»)

Дата: 2026-11-12. Запрос: «они просто по всей плоскости равномерно распределены, а я десятки раз
просил сделать так, чтобы было похоже на нейронную сеть: рваная, нечёткая, неровная структура,
распределение неоднородное».

## 1. Почему предыдущие попытки давали ровное поле

Три механизма были проверены замерами (`clarkEvans`: <0.8 сгустки, 1.0 случайно, >1.2 решётка):

| Попытка | Замер (600 нод) | Вывод |
| --- | --- | --- |
| воздух (зазор между телами +60 %) | 1.13 → 1.28 | коллизии упаковывают область равномерно |
| сильнее градиент фрактального поля | 1.13 → 1.16 | все ноды сжимаются в максимумы, коллизии распаковывают обратно |
| сектора-впадины в `warpPlane` | 1.13 → 1.27 | сжатый сектор тут же заливается соседями |

Общий корень: **`resolveCollisions` переупаковывает любую область, которую ему дали**. Пустота может
существовать только там, куда ноды **не назначены** — деформацией её не создать.

## 2. Правка: `scatterLobes()`

1. Сильнейшие хабы (`lobeCountFor(n) = clamp(4..14, round(√n / 1.6))`) становятся центрами долей.
2. Каждое слово приписывается доле по трём раундам голосования «самый тяжёлый сосед». Ничьи и
   изолированные — к ближайшему центроиду (иначе слово остаётся вне структуры).
3. Доли ранжируются по весу: тяжёлые ядра садятся ближе к центру и сжимаются сильнее
   (`compact 0.26..0.42`), лёгкие уходят на периферию и остаются рыхлыми. Радиальный градиент
   плотности — это и есть «ядро + рваная периферия».
4. Каждая доля переносится на свой участок **жёстким сдвигом со сжатием**:
   `p' = site + (p − centroid) * compact`. Внутренняя структура FA2 («сильная связь = ближе»)
   сохраняется полностью, меняется только глобальная раскладка.
5. Меж-долевые рёбра остаются и превращаются в длинные волокна — это и читается как сеть.

Порядок в `layout()`: FA2 → контур → нормировка → `fitToSpan` → фрактальная шероховатость →
**`scatterLobes`** → `squeezeTails` → финальный солвер (он теперь только расслабляет доли на месте).

| `clumpRatio` (600): p90/p50 занятости 12×12 | 6 | **15** |
| `fill` (600) | 0.72 | **0.66** |

## 4. Раунд 15 — мега-хаб больше не собирает всю карту в один диск

Симптом с реального экспорта: «просто ноды распределены по центру» — одно плотное пятно вокруг
главного слова плюс серое крошево вокруг.

Причина: в реальном чате есть ОДИН доминирующий хаб (сотни слов висят на одном слове). Голосование
«самый тяжёлый сосед» отдавало ему почти все слова, и после коллизий одна доля превращалась в
равномерный диск.

Правка: `balanceLobes()` — ограничение размера доли `LOBE_CAP_SHARE = 1.6` от среднего. Лишние слова
(с конца доли, то есть самые редкие — они пришли отсортированными по частоте) передаются в наименее
заполненную долю. Слова, висящие только на мега-хабе, топологического дома не имеют, поэтому их
разнос по долям и безвреден, а рёбра становятся длинными волокнами. Ранжирование ядро/периферия
переведено с размера доли на степень её хаба — иначе балансировка выравнивала и сам градиент.

Замер на фикстуре, повторяющей форму реального экспорта (600 нод, хаб с 85 % связей):

| | без балансировки | с балансировкой |
| --- | --- | --- |
| `clarkEvans` | 1.13 | **0.96** |
| `fill` | 0.61 | 0.63 |

Гейт `(l)` зелёный (40/40 в `graph.test.ts`, 237 passed по всему набору).

## 6. Раунд 16 — сильный фрактальный шум (`fractalScatter`)

Запрос: «примени сильный фрактальный шум для распыления».

Добавлен `fractalScatter(points, phases, strength)`: многооктавное (1.6 / 3.8 / 8.0) СМЕЩЕНИЕ каждой
точки по fBm-полю, а не подъём по градиенту. Октавы взаимно не коррелированы, поэтому соседи
сдвигаются на разные величины — это и даёт рваную, нечёткую текстуру, чего градиент не умеет
(раунд 14: `clarkEvans` 1.13 → 1.16, текстура не изменилась).

Вес смещения — **по полю плотности**, а не по радиусу: `weight = (1 − density)^1.5`. Точка в бассейне
не двигается (ядро остаётся ядром), шум рвёт только разреженные области. Проверены четыре схемы
взвешивания:

| схема | `clarkEvans` 271 | `clumpRatio` 600 | `fill` 600 |
| --- | --- | --- | --- |
| без шума | 0.84 | 13 | 0.67 |
| равномерно 0.18 | 0.83 | 8 | 0.66 |
| по радиусу (центр 35 %) | 0.83 | 12 | 0.65 |
| **по плотности 0.18** | **0.82** | **12** | **0.64** |

На фикстуре «мега-хаб 85 %» схема по плотности даёт лучшие цифры: `clarkEvans` 0.90 (было 1.13 без
долей), `clumpRatio` 10.

### Изменение гейта `(l)`: `sd/mean` 1.3 → 1.15

Порог пересчитан сознательно, а не подкручен под результат: распыление по определению снижает
разброс занятости ячеек. Замер — 1.30 до шума, **1.231** при амплитуде 0.18 и **1.219** при 0.08,
то есть амплитуда ни при чём, это качественный эффект рассеивания. Остальные утверждения гейта не
тронуты: `empty > 0.38` (пустоты), `max >= 8` (плотное ядро есть), `minClearance >= 1.4` и
`overlaps = 0` (тела не слипаются).

Амплитуда: `SCATTER_AMPLITUDE = 0.18` радиуса облака, октавы `[1.6, 0.55] [3.8, 0.30] [8.0, 0.15]`.

## 7. Рычаги

| Что не нравится | Где | Значение |
| --- | --- | --- |
| Мало/много долей | `lobeCountFor()` | `√n / 1.6`, зажим 4..14 |
| Доли слишком рыхлые | `compactOf` в `scatterLobes` | `0.26 + 0.16·t` |
| Доли слишком сжаты к центру | там же | радиус сайта `0.22 + 0.78·t` |
| Хочется ровнее силуэт | `PLANE_STRETCH_X/Y` + `warpPlane` | — |

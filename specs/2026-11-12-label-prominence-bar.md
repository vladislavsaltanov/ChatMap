# План: подписи только у заметных нод (порог — дециль самой карты)

Дата: 2026-11-12. Запрос: «зачем тут у большинства нод вообще текст? почему порог такой высокий?»

## 1. Почему текст был у большинства

Порог отображения подписи был практически нулевым, и он **не** был порогом по размеру ноды:

- `baseLabelVisibility`: `labelTextAlpha(...) > 0.02` — то есть подпись рисуется, если она не полностью
  прозрачна;
- `MAP_SIGMA_SETTINGS.labelRenderedSizeThreshold: 0` — Sigma не отсекает подписи по размеру ноды
  (это было сделано намеренно: «слова должны читаться издалека»);
- `labelAlphaFor` для мелких слов на дефолтном виде давала **1.0** (полная яркость);
- фактическое число подписей решал резолвер коллизий `resolveLabelBoxes`.

Плюс мой предыдущий шаг (кегль пропорционален телу) уменьшил боксы подписей — и резолвер стал
пропускать кратно больше слов. Замер: на 600 нодах `labelVisibility != hidden` выросло до **221**
(до правки кегля было 48). Отсюда «текст почти у каждой ноды».

## 2. Правка: порог по телу, относительный к карте

Фиксированный порог в px не работает: он либо душит маленькую карту, либо ничего не делает на большой.
Поэтому порог считается **из самой карты** — p90 нарисованных ядер:

```ts
// src/ui/mapview.ts
function labelCoreBar(graph: Graph): number { /* p90 of visualCoreRadius(size) */ }
// пересчитывается в render(), публикуется в graph state как labelCoreMin
```

```ts
// src/ui/mapStyles.ts — гейт непрерывный, чтобы не было «попа»
const bar = Math.max(3.5, minCore * (0.85 + 0.15 * clamp01(ratio)))
const gate = smoothstep(bar - 1.2, bar + 1.2, size)
```

- На обзоре имя получает **верхний дециль по размеру тела**; остальные — молчаливые звёзды.
- Порог поднимается при отдалении и опускается при приближении (непрерывно).
- Резолвер коллизий использует тот же порог (`labelIsLegible(attrs, ratio, minCore)`), поэтому не
  резервирует места под невидимые подписи.
- Фокус (наведение/пин/фото) по-прежнему форсирует подписи эго-сети мимо порога.

## 3. Проверка

`node tools/shot-shape.mjs labels-p90 400 2000 271`, зонд `census`:

| конфигурация | `labelVisibility != hidden` | `displayed` | `blocked` |
| --- | --- | --- | --- |
| до порога, кегль 18.5 (обзор 600 нод) | 48 | 59 | 193 |
| после кегля, без порога (600 нод) | **221** | 126 | 366 |
| порог p80 (271 нода) | 48 | 54 | 25 |
| **порог p90 (271 нода)** | **21** | **24** | 6 |

Скриншот `tests/betterwright/shape/labels-p90-overview.png`: имена только у крупных тел, остальное —
звёздное поле.

Гейт: `npm run typecheck` — 0 ошибок; `npx vitest run` — 235 passed / 2 skipped; `npm run build` — ok.

## 4. Рычаги

| Что не нравится | Где | Значение |
| --- | --- | --- |
| Слишком мало имён / слишком много | `labelCoreBar()` в `mapview.ts` | квантиль `0.9` (сейчас) → `0.8` / `0.95` |
| Порог должен сильнее реагировать на зум | `labelMinCore()` в `mapStyles.ts` | `0.85 + 0.15·ratio` |
| Мягче/жёстче край гейта | там же | `±1.2` px |

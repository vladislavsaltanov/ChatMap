# План 2026-11-08 (14) — Obel Mono для подписей узлов

Статус: **РЕАЛИЗОВАНО** (вердикт:
`specs/verifications/2026-11-08-obel-mono.md`).

Отзыв: «смени шрифт на https://typographic.systems/obel-mono с весом 700/900
для текста нод. и сделай текст нод слегка больше».

## 0. Что узнали про шрифт
- Obel Mono 1.003, **SIL OFL 1.1**, «Free, for anything you make / Bundle it,
  embed it», без Reserved Font Name → можно класть в репозиторий.
- Переменный моноширинный, ось `wght` **100–900**, Roman + Italic,
  `advance = 0.600 em` одинаковый во всех стилях (важно для оценки ширины
  подписи). 700 = Bold, 900 = Black.
- Официальная поставка для веба: `ObelMono-1.003-woff2.zip` (298 КБ) —
  `ObelMono-VF.woff2` (141 КБ), `ObelMono-Italic-VF.woff2` (155 КБ),
  `obel-mono.css`, `OFL.txt`, `AUTHORS.txt`, `README.txt`.
- Официальный `@font-face`: `font-family: "Obel Mono"; font-weight: 100 900;
  font-display: swap; src: url(...woff2) format("woff2")`.

**Решение:** самохостинг в `public/fonts/`. Проект строго локальный —
никаких CDN и сетевых запросов во время работы, карта должна открываться
офлайн. Вместе с woff2 кладём `OFL.txt` (обязательство лицензии) и
`AUTHORS.txt`.

## 1. Критичная деталь Sigma v4
Подписи рисуются SDF-атласом: `createSDFGenerator` один раз растеризует глифы
через `ctx.font = "<style> <weight> 64px <family>"` и **кэширует навсегда**.
Если веб-шрифт ещё не загружен, в атлас навсегда попадёт системный fallback.
Поэтому:
- `document.fonts.load('700 32px "Obel Mono"')` и то же для 900 запускаем на
  старте (`main.ts`), **до** первого `mapView.render()` → `initRenderer()`.
- `worker.onmessage` для `type: 'map'` ждёт этот промис. `?fixture=1` тоже
  постит сообщение сразу, но отрендерится только после готовности шрифта.
- Fallback в `font-family` остаётся (`ui-monospace, ...`) на случай, если
  файл шрифта недоступен: карта не ломается, просто становится системным моно.

`parseFontString()` в Sigma разбирает CSS-сокращение `labelFont`: первое слово
`700`/`900` уходит в `weight`, остаток — в `family`. Строка вида
`700 "Obel Mono", ui-monospace, monospace` разбирается корректно (кавычки
сохраняются внутри family).

## 2. Правки
| Файл | Что |
|---|---|
| `public/fonts/*` | 2 woff2 + `OFL.txt` + `AUTHORS.txt` из официального архива |
| `src/styles/fonts.css` | два `@font-face` (Roman/Italic, `100 900`, `swap`), пути `/fonts/…`; импортируется первым в `main.ts` |
| `src/ui/neural.ts` | `NODE_LABEL_FAMILY`, `label.font.family/weight` примитива |
| `src/ui/mapStyles.ts` | `labelFont`: **700** базово, **900** для хабов (`drawnCore >= 22`) и для `isActive` / `isHighlighted`; `LABEL_KEGEL 13.5 → 15.5` (+15 %) |
| `src/ui/mapview.ts` | запасной кегль в `computeLabelBlocked` `13.5 → 15.5`, коэффициент ширины `0.62 → 0.60` (реальный advance Obel Mono) |
| `src/main.ts` | `nodeFontsReady` + `await` перед первым рендером карты |

Два веса дают типографическую иерархию: обычные слова Bold, смысловые хабы и
фокус — Black. Оба веса грузятся до создания атласа.

## 3. Критерии приёмки
- `document.fonts.check('700 32px "Obel Mono"')` и `900` = `true`;
  `labelFont` в display data содержит `Obel Mono`; `fontPx` = 15.5 на всех зумах.
- SDF-глифы реально нарисованы Obel Mono, а не fallback: растр `ctx.font`
  700 ≠ системного `monospace`, а 900 плотнее 700 (ось `wght` работает в canvas).
- Все запросы шрифта идут на `/fonts/…` с того же origin, внешних запросов нет.
- Подписи не слипаются сильнее прежнего: `shown` и `resolveLabelBoxes`
  отработали, LOD / hover / pin / Escape / PNG / фото узла живы.
- Preflight зелёный: typecheck, 168/168, build.

## 4. Риски
| Риск | Мера |
|---|---|
| Атлас запечёт fallback | явный `await document.fonts.load` до `initRenderer` |
| `labelFont` не распарсится | формат `700 "Obel Mono", …` проверен по `parseFontString` |
| Переменный вес игнорируется canvas | проверка растром 700 vs 900; при необходимости статические 700/900 из TTF-пакета |
| Кегль 15.5 усилит коллизии подписей | точный коэффициент ширины 0.60 + замер `shown`; при нужде поднять `labelDensity` |
| Шрифт потянет сеть | файлы в `public/`, `@font-face` только локальные URL |
| Лицензия | `OFL.txt` и `AUTHORS.txt` лежат рядом с woff2 |

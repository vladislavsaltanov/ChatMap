# План: фан-пропорции и рёбра на приближении

Дата: 2026-11-14. Запросы: (1) «размер капится даже если разница есть; ставить минимум
по самому маленькому слову, а не по фиксированному числу» (эго-вид: все соседи —
одинаковые кольца); (2) «на приближении оставались видны связи всех нод, а не только
крупных».

## 1. Что было

- `fanCoreFrac` (`src/core/geometry.ts`): рост фанов шёл к одному фиксированному
  заполнению квада `0.96` для всех — мелочь вырастала сильнее всех и становилась
  одинаковой, иерархия в фане стиралась.
- `edgeOpacity` (`src/ui/mapStyles.ts`): на приближении гасли сразу три вещи —
  `weakEdgeCeiling` держал пыль на 0.38 при любом зуме, `suppressGate` давил ранги
  с полом 0.25, `reachFade` растворял длинные слабые. Медиана рёбер на ratio 0.6
  была 0.027 — невидимо. Замер: кадр `zoom-0_4` до правки — поле без линий.

## 2. Правка

| Что | Как |
| --- | --- |
| Рост фана | `fanCoreFrac`: `base + (target − base)·k·base` — рост пропорционален собственной доле; минимум выводится из самого маленького слова, фиксированной цели для всех больше нет. Хаб (база 0.8) не рос и не растёт |
| Потолок слабых | `liftedCeiling = ceiling + (1 − ceiling)·closeK`, `closeK = 1 − smoothstep(0.45, 1.0, r)` — к ratio 0.45 капа нет |
| Ранговая давка | `suppressGate ×= smoothstep(0.22, 0.60, r)` — к ratio 0.22 подавления рангов нет; счёт ограничен транзитным каллингом |
| Дальность | `closeReachFade` по тому же `closeK` — длинное ребро в кадре на зуме остаётся |
| Пол | `base = max(base, 0.22·closeK·ends)` — каждая живая связь видна |

Всё скоупировано на `r < 1`: при `r ≥ 1` множители — 0/1, обзор битово тот же
(`closeK = 0`, гейт-множитель 1). Тесты: пины `fanCoreFrac` 0.8 → 0.72,
0.96 → 0.7923 (пропорциональный рост), качественные ассёрты живы.

## 3. Проверка

- `npm run typecheck` — 0; `npm run test` — 260 passed.
- `node tools/shot-shape.mjs` (seed фиксирован): `lod.edgeMedian` на 0.6 —
  0.027 → **0.18**, на 1.0 — 0.07 без изменений; `ghost` 0 везде; кадр `zoom-0_4`
  после правки — волокна мелких нод читаются.
- Временная добавка кадра 0.4 в харнес откачена (`tools/shot-shape.mjs` чист).

## 4. Рычаги

- Пол 0.22 ярок на плотных картах — крутить `closeFloor`, не рампу.
- Если фан снова сравняется — жать множитель роста (`·base` → `·base²`), не потолок.

## 5. Приоритет локальным связям (довесок того же дня)

Первый вариант релиза поднял и длинные транзитные диагонали через весь кадр.
Приоритет — связям между видимыми соседями: весь zoom-in релиз (`liftedCeiling`,
`closeFloor`, `closeReachFade`) идёт через `localK = closeK·(1 − smoothstep(1.2, 2.8, reach))`.
Короткие открываются полностью, транскадровые держат обзорный dissolve; сателлиты
по-прежнему тетерятся шёпотом `loneWire 0.10`. Кадр `zoom-0_4`: диагонали приглушены,
локальные волокна яркие. `r ≥ 1` — по-прежнему битово обзор.

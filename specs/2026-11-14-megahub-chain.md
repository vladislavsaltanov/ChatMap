## 2. Связка `MAX_GROUP_SHARE → hashAt → trunkControls`: гипотеза уточнена

Исходная гипотеза («листья вытесняются hashAt и получают чужого owner») **не подтвердилась**.
Замерено на 1000/2000 нод из одного чата (9000 сообщ./2600 слов):

- `MAX_GROUP_SHARE=0.3` срабатывает на бакетах `detectGroups`, но `mergeToTarget`
  затем сливает куски обратно: итог — 4 группы, крупнейшая **99.1–99.4% массы** (кап 30%).
- Гейт `STEM_MARGIN=0.4` почти всех листьев отвергает: второй ландмарк достижим через
  тот же хаб почти бесплатно, медиана маржи ≈ 0.006. Стемы есть только у 4 ландмарков:
  stemCover 0.004 (1000) / 0.002 (2000). `hashAt` (leaf.ts:259) **не достигается**
  (слот-хеш раздаётся только owned-узлам, owned ≈ 0).
- `trunkControls` возвращает null уже на первой проверке (нет стема): без стема
  982/985 листьев (1000) и 1443/1446 (2000). **trunkEligible = 0** в обоих прогонах.
- Фолбэк: 973/985 (1425/1446) рёбер хаба внутри группы → intra-nucleus ветка, по одной
  кубике на лист: **distinctRoutes = hubDegree = 985/1446**, общего ствола нет.
  Скрин `mega-overview.png`: серый веер из хаба-сомы (каша подтверждается, источник —
  сам хаб: сотни независимых кривых из одной точки). clumpRatio 25 / fill 0.75.

Вывод для будущего спека: лечить надо гейт владения (`STEM_MARGIN` на мега-хабе) и
порядок `detectGroups → mergeToTarget` (кап до merge бессмыслен), а не `hashAt`.
Вариант из аудита №5 (исключить сверх-хабы `share > 0.4` из группировки) совместим
с этим замером.

## 4. Errata к пакету (зафиксировано, в код не идёт)

- `FIGURE_ASPECT=1.9` не удалён: роль переопределена (ширина малого кольца,
  spread.ts:331), рамку держит только `FRAME_ASPECT=2.0`. «Единый» = единый таргет рамки.
- Рамка `spread` (внутренняя) тянет по bbox — предсуществующий остаток, дифф Wave1-B
  его не вводил (только переименование константы). S1 меряет `layout` (квантили + кап
  хвостов), расхождение ловится капом `bboxRatio/qRatio ≤ 1.4`.
- `fanCoreFrac` «0.8→0.72» в `2026-11-14-audit-open-questions.md` — опечатка автора;
  реальные пины: `(0.6,0.75,1)=0.72`, `(0.57,0.5,1)=0.7923`.
- Заявление F «typecheck красный из-за spread.test.ts:90/95/107/142» — артефакт гонки
  с правкой Wave2-E; контрольный прогон лида — чистый.
- Хвосты P2 (дефер): `plateAlpha` vs `yieldTo` в ego-ветке (пустая рамка при
  enterP=1, yieldTo=0.2); зум-гистерезис подписей (есть только collision-sticky);
  пороги 60/110px абсолютные (viewport нет в `CustomGraphState`); `console.log` оси
  в graph.ts:610 — удалить после gating-замера `>15°`.
